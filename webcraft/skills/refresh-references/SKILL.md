# refresh-references

대상: $ARGUMENTS

인자가 비어 있으면 사용자의 말에서 노트 id나 사이트 이름을 찾는다. 말에도 없으면 6개월 넘은 노트 전부가 대상이다.

라이브러리 폴더는 이 스킬 기준 폴더의 `../web-design/library/references/`다.

## 할 일

1. 대상을 정한다. 인자로 id가 있으면 그것만, 없으면 `index.md`에서 `analyzed_at`이 오늘로부터 6개월보다 오래된 것 전부.
2. 대상이 10개를 넘으면 목록을 보여주고 진행할지 묻는다.
3. 대상마다 `add-reference`와 같은 방법으로 사이트를 다시 보고 노트를 새로 쓴다. `measure.js`와 `interact-probe.js`로 실측 수치도 새로 잰다. 바뀐 점이 크면 노트 맨 아래에 `## 이전과 달라진 점`을 남긴다.
4. 사이트가 사라졌거나 완전히 바뀌어 더는 레퍼런스로 쓸 수 없으면, 노트를 지우지 말고 사용자에게 알린다.
5. `index.md`의 `analyzed_at`과 바뀐 styles, mood를 고친다.

## 마무리

다시 분석한 노트, 크게 바뀐 노트, 열지 못한 사이트를 나눠서 알린다.
