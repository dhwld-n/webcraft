# AI 느낌 금지 목록

AI가 만든 사이트에서 반복되는 패턴이다. 스타일 카드가 명시적으로 요구하지 않는 한 쓰지 않는다. 오른쪽이 대신할 방법이다.

다른 도구(디자인 훅, 검사기)가 흔한 글꼴이나 팔레트를 경고하면 "사용자가 확인함"으로 끄지 않는다. 대안을 하나 보여 주고 다시 묻는다.

## 흔한 첫 화면 틀
첫 화면을 한 문장으로 적어 봤을 때 아래 중 하나와 같으면 다시 짠다. 하나하나는 괜찮아도 **조합이 같으면** AI 티가 난다.
| 틀 | 대신 |
|---|---|
| SaaS: 알약 배지 → 가운데 두 줄 제목(둘째 줄 흐림이나 강조색) → 설명 → 버튼 두 개나 이메일 칸 → 기울인 제품 화면 | 왼쪽이나 비대칭 제목, 제품의 핵심 한 부분만 크게, 버튼 하나 |
| 다크 테크: 남색 검정 + 격자·점 + 파란 빛 번짐 + 라임·형광 노랑 버튼 + 영문 대문자 모노 라벨 | 배경색과 강조색을 흔하지 않게, 빛 대신 선·숫자·실제 데이터 |
| 따뜻한 브랜드: 미색 바탕 + 가운데 큰 명조 + 자간 넓은 작은 라벨 + 얇은 선 | 사진이나 글이 화면을 꽉 채우는 비대칭, 미색이 아닌 종이색 |
| 포트폴리오: 거대한 이름 + "01 / 02" 번호 목록 + 태그 칩 + 호버 미리보기 | 작업 하나를 크게 먼저, 목록은 그다음 |
| 섹션 반복: 작은 라벨 + 큰 제목 + 설명 + 카드나 번호 줄을 모든 섹션에 | 섹션마다 내용에 맞는 틀 (표, 큰 숫자 하나, 긴 글, 사진 한 장) |

## 디자인
| 피할 것 | 대신 |
|---|---|
| UI 키트 기본 조합: 어두운 `#121212` 바탕 + 파랑 강조 + 둥근 카드 4열 + 가운데 큰 문장 + 3D 휴대폰 목업 + 등각 3D 일러스트 (UI8 홈 실측, 2026-11) | 레퍼런스 노트의 구도 하나를 원리로 가져오고, 목업 대신 실제 화면이나 사진 |
| 보라-파랑 그라데이션 배경, 버튼 | 팔레트의 단색 하나 + 명도 차이 |
| 글자에 그라데이션 (`background-clip: text`) | 단색 글자. 강조는 굵기, 크기, 색 하나로 |
| 의미 없는 빛 번짐, 흐릿한 원 여러 개 | 레퍼런스에서 온 질감 하나 (그레인, 선, 사진) 또는 없음 |
| 아이콘 자리에 이모지 (🚀 ✨ 💡) | 단순한 선 아이콘, 숫자, 짧은 라벨, 또는 실제 이미지 |
| 모든 것을 가운데 정렬 | 왼쪽 정렬 기본. 가운데는 히어로 한 곳 정도 |
| 똑같은 카드 3개 나열 (아이콘 + 제목 + 두 줄) | 크기가 다른 칸, 번호 목록, 한 기능만 크게 보여주기 |
| 제품 화면이 모든 칸에 글자가 찬 표, 회색 덩어리, 카드 속 축소 스크린샷 | `guide/product-ui.md`의 기준대로: 실제 글자는 3~7개, 창은 가장자리 밖으로 |
| 사이트의 상황과 어긋난 글꼴 (회계 서비스에 명조, 젊은 브랜드에 오래돼 보이는 폰트) | 상황부터 정하고 고른다. 실용적인 사이트는 단정한 고딕이 맞다 |
| 분위기가 중요한 사이트에서 제목, 본문 모두 무난한 기본 고딕 | 제목에 분위기 있는 폰트, 본문도 분위기에 맞게 |
| 요즘 AI가 즐겨 쓰는 제목 폰트 (Space Grotesk, Geist, Manrope, Sora, Instrument Serif, Fraunces, Playfair Display, Cormorant) | 눈누나 Fontshare 폰트, 덜 알려진 Google 폰트 |
| 제목 위 알약 모양 배지 ("New · 무엇이 출시됨") | 배지 없이 제목부터. 소식은 내비 옆 한 줄 글자로 |
| 제목 둘째 줄만 흐리게 하거나 강조색 | 제목은 한 색. 강조는 크기나 굵기 |
| 어두운 바탕 + 라임·형광 노랑 버튼 | 흔하지 않은 강조색, 또는 흰 버튼 하나 |
| 라벨마다 영문 대문자 모노 + 넓은 자간 | 한글 라벨, 또는 라벨 없이 제목만 |
| 알약 태그 칩 여러 개 | 쉼표로 이은 글자 한 줄 |
| 사진 자리에 그려 넣은 가짜 풍경 (산 능선, 달, 그라데이션 하늘) | 단색 톤 블록 + "사진 자리표시: 무엇" 글자 |
| 입장·로딩 화면이 가운데 원과 큰 퍼센트 숫자 | 콘셉트의 물건이나 장면이 차오르는 화면 |
| 3D 위 글자가 네 모서리 + 왼쪽 아래 큰 제목 + 아래 진행 막대 | 콘셉트에 맞춘 다른 배치 (위쪽 띠, 세로 단, 물체 곁의 글자) |
| 모서리 전부 같은 큰 둥글기 + 옅은 그림자 카드 | 스타일 카드의 질감을 따른다 |
| 의미 없는 장식 모션 (모든 요소가 떠오름) | 주인공 모션 하나, 나머지는 조용히 |

## 구조
- 히어로 → 기능 3개 → 후기 3개 → 가격 3단 → FAQ → 큰 CTA 순서를 그대로 따르지 않는다. 이 페이지에 정말 필요한 섹션만, 중요한 순서대로
- 섹션마다 "작은 라벨 + 큰 제목 + 설명 한 줄 + 버튼" 틀을 반복하지 않는다
- 뭐든 세 개씩 나열하지 않는다. 실제 개수대로

## 문구
**세부 설명을 넣지 않는다.** 한 섹션은 하나만 말한다. 글자 수보다 종류가 문제다. 화면당 글자 수는 좋은 사이트끼리도 34자에서 1,300자까지 다르다.

| 피할 것 | 대신 |
|---|---|
| 제목 위아래의 작은 라벨, 장 번호, 태그 | 뺀다 |
| 여백 주석, 용어 풀이, 사진 설명, 각주 | 뺀다. 꼭 필요한 정보만 본문에 |
| 표나 목록의 칸마다 붙은 설명 | 이름과 숫자만 |
| 제목이 한 말을 설명이 다시 하는 문장 | 설명을 지운다 |
| 만드는 과정, 작동 원리를 전부 설명하기 | 보는 사람이 결정하는 데 필요한 것만 |
| 사용자가 말하지 않은 사실 지어내기 (공정, 수치, 일화) | 쓰지 않는다 |
| 혁신적인, 새로운 차원의, 차원이 다른, 완벽한 솔루션 | 실제로 하는 일을 구체적으로 ("매일 아침 9시에 물 줄 화분을 알려줘요") |
| 한 단계 업그레이드, 경험을 극대화, 손쉽게, 원활한 | 숫자나 장면 ("3초면 등록", "출근길에 확인") |
| 지금 바로 시작해보세요!, ~해보세요! 남발 | 버튼은 동사 하나 ("시작하기", "앱 받기"). 느낌표는 쓰지 않는다 |
| seamless, unlock, empower, elevate, revolutionize, next-level, cutting-edge, supercharge, effortless | 구체적인 동사와 명사 |
| 모든 문장을 같은 길이, 같은 리듬으로 | 짧은 문장과 긴 문장을 섞는다 |
| 사용자가 준 적 없는 가짜 수치와 후기 ("10만 명이 선택한") | 자리표시로 두고 사용자에게 채우라고 알린다 |

## 코드
- 보이지 않는 문자(폭 없는 공백 등)를 남기지 않는다
- 클래스 이름, 주석에 "AI generated", "Lorem ipsum" 같은 흔적을 남기지 않는다
