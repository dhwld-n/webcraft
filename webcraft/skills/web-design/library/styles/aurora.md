# aurora

밤하늘의 오로라처럼 부드러운 빛의 띠가 어두운 바탕 위에서 천천히 흐른다. 색은 강하지만 경계가 흐려서 시끄럽지 않다. 빛이 배경이고, 그 위의 글자와 판은 아주 단정해야 한다.

**어울리는 곳:** 명상·수면·웰빙, 음악·오디오, 천문·과학, 크리에이티브 도구, 향수·화장품, 행사 티저

**참고:** Craft, Passionfroot, Ondo Collective(그라데이션 바탕의 부드러움), daisyUI의 aqua·abyss 테마 토큰

## 뻔한 버전 (이렇게 나오면 실패)
- 보라·분홍·파랑 흐린 원 세 개를 검정 바탕에 깔고 가운데 흰 제목 + 반투명 카드 셋 (가장 흔한 AI 랜딩)
- 색을 다섯 가지 이상 섞어 진흙색이 된다
- 빛이 움직이지 않고 그냥 박혀 있다

## 레이아웃
- 첫 화면은 빛이 70% 이상. 글은 작은 덩어리로 한쪽에
- 빛의 띠는 화면을 비스듬히 가로지르거나 아래에서 피어오른다. 가운데 원형으로 모으지 않는다
- 아래 섹션으로 갈수록 빛이 줄고 어두운 면이 늘어난다. 빛은 첫 화면과 마지막 행동 유도에만
- 판(카드)은 거의 없다. 필요하면 테두리 1px만 있는 어두운 판

## 타이포
- 가볍고 넓은 산세리프 (Syne, Unbounded는 제목 한 줄에만, 본문은 Instrument Sans, General Sans / 한글 Pretendard, SUIT)
- 제목은 굵기 400~500, 크게. 빛 위에서 굵은 글자는 무거워 보인다
- 작은 글자는 바탕보다 아주 살짝 밝은 회색이 아니라 흰색 70~80%

## 색
- 바탕: 순검정 대신 색을 품은 어둠 (남색 `#070a14`, 심해 `#03171a`, 보라 밤 `#0d0716`)
- 빛: 같은 온도의 2~3색 (초록 `#3dffb0` + 청록 `#2fd0ff` + 보라 `#8a5cff`, 또는 주황 `#ff8a3d` + 분홍 `#ff4fa3`)
- 빛은 채도 높게, 대신 흐림 80~140px과 투명도 0.5~0.8로 부드럽게

## 질감
- 빛 위에 아주 옅은 그레인을 깔면 색 띠(밴딩)가 안 보이고 필름 같다 (`grain-gradient`)
- 별가루 몇 개 (`particle-field`를 선 없이, 아주 적게)
- 테두리 1px `rgb(255 255 255 / 0.12)`, 그림자 없음

### 비슷한 스타일과 구별
- **그레이니 그라데이션:** 밝은 바탕에도 쓰고 정지해 있다. 오로라는 어둠 위의 움직이는 빛
- **사이버펑크:** 날카로운 네온 선과 글리치. 오로라는 경계가 없다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  --max: 1280px; --margin: clamp(20px, 5vw, 72px); --gap: clamp(16px, 2.4vw, 32px);
  /* 빛: 2~3색, 크게 흐리게 */
  --glow-1: #3dffb0; --glow-2: #2fd0ff; --glow-3: #8a5cff;
  --glow-blur: 110px; --glow-alpha: 0.7; --glow-speed: 18s;
  /* 글자 크기 */
  --fs-sm: 14px; --fs-base: 17px; --fs-lg: 24px; --fs-hero: clamp(44px, 7vw, 112px);
  --fw-body: 400; --fw-head: 450; --lh-head: 1.0; --lh-body: 1.6; --ls-head: -0.03em;
  /* 모양 */
  --r: 14px; --line: 1px solid rgb(255 255 255 / 0.12);
  /* 움직임: 아주 느리게 */
  --ease: cubic-bezier(0.45, 0, 0.55, 1); --dur-2: 900ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example aurora` (구현할 때 한 번)

## 어울리는 모션
- 빛의 띠가 15~25초 주기로 천천히 일렁인다 (모범 섹션 코드)
- 커서 쪽으로 빛이 살짝 끌려온다 (빛 층 하나에 `--mx` 변수)
- 별가루 (`particle-field`, 선 없음, density 0.00005)
- 강도: 낮음~중간. 빠른 움직임은 오로라가 아니다

## 하지 말 것
- 흐린 원 세 개를 가운데 모으기 (가장 흔한 AI 배경)
- 빛 위에 반투명 카드 여러 장 (`liquid-glass`를 쓰려면 한 곳만)
- 순검정 바탕 (빛이 붕 뜬다)
- 모든 섹션에 빛 (첫 화면과 끝에만)
