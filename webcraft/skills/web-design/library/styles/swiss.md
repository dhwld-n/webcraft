# swiss

스위스 국제 타이포그래피 양식. 엄격한 그리드, 굵은 산세리프, 왼쪽 정렬, 원색 하나. 장식 대신 **정보의 구조 자체가 그래픽**이 된다. 숫자, 표, 일정, 지도처럼 정리할 정보가 많을 때 가장 빛난다.

**어울리는 곳:** 디자인 행사·전시, 건축·도시, 교통·공공, 데이터 서비스, 교육 기관, 출판사, B2B 도구

**참고:** 서울디자인페스티벌, 삼성디자인, Planet, Anubi, beautiful-ui, daisyUI의 nord·lofi 테마 토큰

## 뻔한 버전 (이렇게 나오면 실패)
- 흰 바탕 + 빨강 + Helvetica 느낌 글꼴만 쓰고 그리드는 그냥 가운데 한 단
- 포스터 흉내로 큰 숫자를 아무 데나 크게 (구조와 상관없이)
- 굵은 제목 + 얇은 회색 본문만 있고 정보 정리가 없다

## 레이아웃
- **눈에 보이는 그리드.** 6열 또는 12열, 가는 선으로 칸을 드러내도 좋다. 모든 요소의 왼쪽 끝이 그리드 선에 맞는다
- 왼쪽 정렬, 오른쪽은 들쭉날쭉. 가운데 정렬 없음
- 큰 제목이 칸을 가로지르고, 작은 정보 덩어리(날짜, 장소, 번호)가 칸 안에 정확히 놓인다
- 섹션 번호(01, 02 …)와 칸 머리글로 정보 구조를 보여 준다

## 타이포
- 그로테스크 산세리프 하나 (영문 Inter, Hanken Grotesk, Instrument Sans / 한글 Pretendard, 펴진고딕, IBM Plex Sans KR)
- 굵기 대비: 제목 700~800, 본문 400. 제목 행간 0.9~1.0, 자간 -0.03~-0.05em
- 크기 단계를 적게 (4~5단계). 같은 역할은 반드시 같은 크기
- 숫자가 주인공일 때가 많다. 고정폭 숫자, 큰 숫자와 작은 단위

## 색
- 흰색(또는 밝은 회색) + 검정 + 원색 하나 (빨강 `#e3001b` 계열, 파랑 `#0044ff`, 노랑 `#ffd400` 중 하나)
- 원색은 면으로 크게 쓰거나 아주 작게 쓰거나 둘 중 하나. 중간 크기로 여기저기 쓰지 않는다

## 질감
- 선: 1px 또는 2px 검정, 칸 경계
- 그림자 없음, 둥글기 0
- 사진은 흑백이나 원색 한 가지로 덮어도 좋다 (`mix-blend-mode: multiply`)

### 비슷한 스타일과 구별
- **미니멀리즘:** 비움이 주인공. 스위스는 구조와 정보가 주인공이고 더 빽빽해도 된다
- **네오 브루탈리즘:** 두꺼운 테두리와 그림자, 장난기. 스위스는 차갑고 정확하다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 12열, 칸 사이를 좁게. 칸 경계를 선으로 보여도 된다 */
  --max: 1440px; --margin: clamp(16px, 3vw, 40px); --gap: clamp(12px, 1.5vw, 20px); --cols: 12;
  --rule: 1px solid var(--text); --rule-bold: 2px solid var(--text);
  /* 크기: 4단계. 같은 역할은 같은 크기 */
  --fs-sm: 13px; --fs-base: 16px; --fs-lg: clamp(24px, 2.6vw, 36px); --fs-hero: clamp(56px, 11vw, 176px);
  --fw-body: 400; --fw-head: 750; --lh-head: 0.92; --lh-body: 1.4; --ls-head: -0.045em;
  /* 모양: 각지게 */
  --r: 0;
  /* 움직임: 빠르고 정확하게 */
  --ease: cubic-bezier(0.2, 0, 0, 1); --dur-1: 120ms; --dur-2: 400ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example swiss` (구현할 때 한 번)

## 어울리는 모션
- 숫자가 굴러 올라가는 카운터 (`odometer`)
- 섹션 바탕이 원색으로 바뀌는 전환 (`section-color-shift`)
- 글자 줄이 칸을 따라 미끄러져 들어오는 등장 (`scroll-reveal`, 가로 방향)
- 강도: 낮음~중간. 빠르고 딱 떨어지는 곡선

## 하지 말 것
- 가운데 정렬, 둥근 모서리, 그림자, 그라데이션
- 원색 두 가지 이상
- 글꼴 세 개 이상
- 그리드에 안 맞는 요소 (하나라도 어긋나면 스위스가 아니다)
