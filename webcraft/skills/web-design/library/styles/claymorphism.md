# claymorphism

점토로 빚은 듯 말랑하고 통통한 화면. 두꺼운 둥근 면이 바탕에서 부풀어 오른 것처럼 보이고, 무광 파스텔이라 귀엽고 친근하다.

**어울리는 곳:** 키즈·교육 앱, 핀테크(친근한 쪽), 건강·명상, 스마트홈, 캐주얼 게임, 3D 일러스트가 있는 랜딩

**참고:** gparkkii 블로그 "CSS로 글래스모피즘, 뉴모피즘, 클레이모피즘 구현하기"(그림자 구성 원리), Magnific의 클레이모피즘 UI 예시들(연보라 바탕의 부푼 흰 패널, 3D 손, 복숭아색 오가닉 3D 햅틱 키트). 이미지는 저작물이므로 원리만 참고한다

## 뻔한 버전 (이렇게 나오면 실패)
- 연보라 바탕 + 흰 부푼 카드 3개 + 카드마다 3D 아이콘 하나 + 가운데 정렬 제목
- 3D 일러스트 없이 그림자만 클레이라 그냥 둥근 카드처럼 보임

## 레이아웃
- 큰 덩어리 몇 개로 단순하게. 카드 수를 줄이고 하나하나를 크게
- 카드 사이 간격 넉넉하게 (24~40px). 덩어리끼리 붙으면 뭉개져 보인다
- 3D 일러스트(손, 아이콘, 캐릭터)를 카드 가장자리에 걸치게 배치해 공간감
- 모바일에서도 덩어리 느낌 유지. 카드 높이를 줄이기보다 개수를 줄인다

## 타이포
- 둥근 고딕: 영문 Nunito, Quicksand, Baloo / 한글 나눔스퀘어라운드, 둥근모꼴 계열, Pretendard(무난한 대안)
- 굵기 600~800. 가는 글자는 통통한 면 위에서 약해 보인다
- 제목 크기 대비는 적당히. 귀여움이 핵심이라 극단적 대비는 피한다

## 색
- 바탕: 파스텔 한 가지 (연보라 `#e9e4ff`, 복숭아 `#ffe6dc`, 하늘 `#dff1ff` 같은)
- 카드: 흰색이나 바탕보다 밝은 파스텔
- 강조: 바탕과 어울리는 진한 파스텔 1~2개 (하늘색 알약 버튼, 복숭아 아이콘)
- **글자는 진하게.** 파스텔 위 파스텔 글자는 대비 실패. 본문은 바탕 색의 아주 진한 톤(예: 연보라 바탕이면 `#2f2463`)

## 질감
핵심은 그림자 네 겹이다. 검정 그림자를 쓰지 않고 **바탕색 계열로 물든 그림자**를 쓴다.

```css
.clay {
  border-radius: 28px;
  background: #ffffff;
  box-shadow:
    0 24px 48px -12px rgb(126 104 230 / 0.45),   /* 1. 아래로 떨어지는 물든 그림자 */
    inset 0 -8px 16px rgb(126 104 230 / 0.35),   /* 2. 아래쪽 안으로 말려 들어가는 그늘 */
    inset 0 10px 24px rgb(255 255 255 / 0.9);    /* 3. 위쪽 볼록한 하이라이트 */
}
```
4. 모서리는 크게 (카드 24~32px, 버튼은 완전 알약). 테두리선은 쓰지 않는다

`--clay-tint`(위 예시의 `126 104 230`)를 바탕색보다 진한 같은 계열로 바꾸면 어느 파스텔에도 맞출 수 있다. 바로 쓸 수 있는 코드는 `clay-surface` 레시피에 있다.

### 비슷한 스타일과 구별
- **뉴모피즘:** 카드와 바탕이 같은 색이고, 왼쪽 위 흰 그림자 + 오른쪽 아래 어두운 그림자 두 개로 "튀어나온 판"을 만든다. 클레이는 카드가 바탕보다 밝고, 그림자가 색을 띠며, 안쪽 그림자로 "통통함"을 만든다
- **글래스모피즘:** 반투명 + 뒤 흐림 + 밝은 테두리. 클레이는 불투명하고 무광이다 (블로그 예시처럼 약한 흐림을 섞을 수는 있다)

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 덩어리 몇 개. 간격은 넉넉하게 */
  --max: 1200px; --margin: clamp(18px, 5vw, 64px); --gap: clamp(20px, 3vw, 40px);
  /* 둥글기: 덩어리 크기에 비례. 버튼은 알약 */
  --r-sm: 18px; --r-md: 28px; --r-lg: 44px; --r-pill: 999px; --pad: clamp(22px, 3vw, 40px);
  /* 그림자: 바탕색 계열로 물든 세 겹 (claymorphism 질감 참고). --clay-tint는 바탕보다 진한 같은 계열 RGB */
  --clay-tint: 126 104 230;
  --clay: 0 24px 48px -12px rgb(var(--clay-tint) / 0.45), inset 0 -8px 16px rgb(var(--clay-tint) / 0.35), inset 0 10px 24px rgb(255 255 255 / 0.9);
  --clay-press: 0 8px 16px -8px rgb(var(--clay-tint) / 0.45), inset 0 -4px 10px rgb(var(--clay-tint) / 0.3), inset 0 6px 14px rgb(255 255 255 / 0.8);
  /* 글자 크기: 1.25배 단계, 굵게. 극단적 대비는 피한다 */
  --fs-sm: 15px; --fs-base: 17px; --fs-md: 21px; --fs-lg: 27px; --fs-xl: 34px; --fs-hero: clamp(40px, 6vw, 76px);
  --fw-body: 600; --fw-head: 800; --lh-head: 1.12; --lh-body: 1.55;
  /* 움직임: 말랑하게 튀어 오른다 */
  --spring: cubic-bezier(0.34, 1.56, 0.64, 1); --dur-1: 160ms; --dur-2: 420ms; --float: 6s;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example claymorphism` (구현할 때 한 번)

## 어울리는 모션
- 누르면 말랑하게 눌렸다 튕겨 나오는 반응 (`cushion-button` 레시피)
- 아이콘이나 3D 오브젝트가 천천히 둥실 떠 있는 움직임
- 등장할 때 살짝 튀는 스프링 (`scroll-reveal`의 이징을 오버슈트 곡선으로)
- 강도: 중간. 빠르고 날카로운 움직임은 어울리지 않는다

## 하지 말 것
- 검정 그림자 (점토가 아니라 플라스틱처럼 보인다)
- 날카로운 모서리, 1px 테두리선, 가는 아이콘 선
- 파스텔을 4가지 이상 (유치해진다)
- 파스텔 위 연한 글자 (`contrast.mjs`로 반드시 확인)
- 모든 요소를 클레이로 (작은 텍스트 버튼, 표, 긴 본문은 평평하게 두는 게 읽기 좋다)
- 카드 안에 카드 안에 카드 (그림자가 겹겹이 쌓여 지저분해진다)
