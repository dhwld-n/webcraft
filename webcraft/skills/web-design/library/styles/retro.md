# retro

70~90년대 인쇄물과 간판의 따뜻함. 바랜 크림 종이, 머스터드·주황·갈색·올리브, 굵고 둥근 세리프, 무지개 줄무늬, 둥근 모서리 사진, 오래된 상표 같은 배지. 새것인데 오래 쓴 것처럼 정겹다.

**어울리는 곳:** 카페·베이커리·식당, 수제 맥주·음료, 레코드 가게, 빈티지 의류, 동네 가게, 캠핑·여행

**참고:** Royal Beverage, Ellis Butchers 리브랜드(크림 `#f3ede8` + 숲색 `#0e4524` + 주황 `#e04a1b`, 넓은 굵은 산세리프 + 책 세리프 본문), daisyUI의 retro(바랜 미색 `oklch(91.6% .034 91)` + 갈색 + 살구·민트·머스터드)·caramellatte(노이즈 1) 테마 토큰

## 뻔한 버전 (이렇게 나오면 실패)
- 갈색 바탕 + Lobster 글꼴 + "Since 1970" 배지 (어디서나 본 빈티지 템플릿)
- 바랜 효과 없이 원색 그대로 (레트로가 아니라 그냥 촌스럽다)
- 낡은 종이 텍스처 이미지를 화면 전체에 진하게

## 레이아웃
- 포스터·메뉴판·레코드 재킷 구도: 큰 제목 하나 + 둥근 배지 + 줄무늬 띠
- 가운데 정렬도 괜찮다 (옛 인쇄물은 대칭이 많다). 대신 위아래 여백 리듬을 뚜렷하게
- 사진은 둥근 모서리(24~40px)나 아치 모양으로 오린다
- 섹션 사이에 3~5줄 무지개 줄무늬(머스터드·주황·빨강·갈색)를 구분선으로

## 타이포
- 제목: 둥글고 굵은 세리프나 70년대 디스플레이 (Caprasimo, Corben, Shrikhand, Righteous, Young Serif / 한글 을지로체, 대구북성로, Song Myung, Yeon Sung)
- 본문: 단정한 책 세리프나 고딕 (Fraunces, Literata 계열 / 한글 고운바탕, Pretendard)
- 제목 행간 0.95, 자간 -0.01em. 둥근 세리프는 너무 좁히면 뭉친다

## 색
- 바탕: 바랜 크림 `#f4ead5`, 종이 `#efe3c8`
- 주조: 머스터드 `#e0a526`, 주황 `#d9622b`, 적갈색 `#9c3d1f`, 올리브 `#6b6a2f`, 짙은 갈색 `#3b2414` 중 3~4개
- 채도를 조금 낮춘 색만. 순백·순검정 없음

## 질감
- 옅은 그레인 (`grain-gradient`, 투명도 0.08~0.15)
- 인쇄 어긋남: 글자 그림자를 다른 색으로 2~3px 어긋나게
- 배지: 둥근 원 + 원을 따라 도는 글자(SVG `textPath`)

### 비슷한 스타일과 구별
- **레트로 픽셀:** 게임 화면 도트. 레트로는 인쇄물과 간판
- **보헤미안:** 자연물, 손으로 짠 무늬, 흙색. 레트로는 상업 인쇄물의 쨍한 70년대색
- **빅토리안:** 장식 테두리와 고전 세리프, 19세기. 레트로는 20세기 후반

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  --max: 1200px; --margin: clamp(18px, 4vw, 56px); --gap: clamp(14px, 2vw, 28px);
  --cream: #f4ead5; --mustard: #e0a526; --orange: #d9622b; --rust: #9c3d1f; --brown: #3b2414;
  /* 줄무늬: 70년대 띠 */
  --stripes: linear-gradient(var(--mustard) 0 25%, var(--orange) 0 50%, var(--rust) 0 75%, var(--brown) 0);
  /* 모양: 둥근 사진, 배지 */
  --r-photo: 32px; --r-arch: 999px 999px 24px 24px; --r-pill: 999px;
  /* 인쇄 어긋남 */
  --misprint: 3px 3px 0 var(--orange);
  /* 글자 */
  --fs-sm: 14px; --fs-base: 17px; --fs-lg: clamp(24px, 3vw, 36px); --fs-hero: clamp(56px, 10vw, 150px);
  --fw-body: 400; --fw-head: 400; --lh-head: 0.95; --lh-body: 1.6; --ls-head: -0.01em;
  /* 움직임: 느긋하게 */
  --ease: cubic-bezier(0.33, 1, 0.68, 1); --dur-1: 200ms; --dur-2: 700ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example retro` (구현할 때 한 번)

## 어울리는 모션
- 배지가 천천히 돈다 (20초에 한 바퀴)
- 줄무늬 띠가 옆으로 흐른다 (`marquee`, 느리게)
- 섹션 바탕이 크림 ↔ 머스터드로 바뀐다 (`section-color-shift`)
- 강도: 낮음~중간
