# vector-art

깨끗한 도형으로 그린 일러스트가 주인공인 화면. 평평한 색 면, 굵기가 일정한 선, 단순한 원·사각·곡선으로 사람과 물건과 풍경을 그린다. 친근하고 설명하기 좋다. 일러스트와 UI가 같은 선 굵기, 같은 둥글기, 같은 팔레트를 쓴다.

**어울리는 곳:** 앱 소개, 교육·어린이, 공공 서비스 안내, 핀테크(친근한 쪽), 건강, 비영리, 온보딩 화면

**참고:** daisyUI의 pastel·lemonade 테마 토큰(라벤더·복숭아·민트, 둥글기 1~2rem, 테두리 2px), Gumroad(굵은 선 일러스트와 원색)

## 뻔한 버전 (이렇게 나오면 실패)
- 팔다리가 길고 얼굴 없는 보라색 사람 일러스트 (가장 흔한 무료 일러스트 스타일)
- 등각(아이소메트릭) 3D 빈 화면 그림 (UI 키트 기본값)
- 일러스트는 둥글고 굵은데 UI는 날카롭고 가늘다 (따로 논다)

## 레이아웃
- 큰 일러스트 장면 하나가 첫 화면의 절반 이상
- 일러스트 조각(별, 잎, 구름)이 섹션 경계를 넘어 다음 섹션으로 이어진다
- 기능 설명은 작은 그림 + 짧은 문장. 그림마다 장면이 다르다 (아이콘 줄이 아니라 작은 이야기)
- 여백은 넉넉하고 정렬은 단순하게

## 타이포
- 둥글거나 기하학적인 산세리프 (Outfit, Figtree, Fredoka, Plus Jakarta Sans / 한글 카페24써라운드, 나눔스퀘어라운드, 고운돋움, Pretendard)
- 굵기 600~700 제목. 일러스트 선 굵기와 글자 획 굵기를 비슷하게 맞추면 한 세계가 된다
- 크기 대비는 중간 (제목은 본문의 3~4배)

## 색
- 4~6색 팔레트를 일러스트와 UI가 같이 쓴다 (예: 크림 `#fff8ec`, 짙은 남색 선 `#1d2347`, 토마토 `#ff6b4a`, 해바라기 `#ffc145`, 민트 `#3ec7a3`, 하늘 `#7cc6ff`)
- 선 색은 순검정 대신 짙은 남색이나 갈색
- 그림자는 그라데이션 대신 한 단계 진한 같은 색 면

## 질감
- 선 굵기 하나로 통일 (2.5~3px). SVG `stroke-width`와 UI 테두리를 같은 값으로
- 둥근 선 끝 (`stroke-linecap: round`)
- 그레인 없이 깨끗하게. 질감이 필요하면 점 무늬 하나

### 비슷한 스타일과 구별
- **클레이모피즘:** 부푼 3D 덩어리. 벡터는 평평한 2D
- **팝아트:** 망점과 만화 화법, 검정 굵은 윤곽. 벡터는 깨끗하고 친절하다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  --max: 1240px; --margin: clamp(18px, 4vw, 56px); --gap: clamp(16px, 2.4vw, 32px);
  /* 일러스트와 UI가 같이 쓰는 값 */
  --ink: #1d2347; --stroke: 3px; --r-sm: 12px; --r-md: 20px; --r-lg: 32px; --r-pill: 999px;
  --tomato: #ff6b4a; --sun: #ffc145; --mint: #3ec7a3; --sky: #7cc6ff; --cream: #fff8ec;
  --flat-shadow: 0 6px 0 color-mix(in srgb, var(--ink) 85%, transparent);
  /* 글자 */
  --fs-sm: 15px; --fs-base: 17px; --fs-lg: 26px; --fs-hero: clamp(42px, 6vw, 88px);
  --fw-body: 500; --fw-head: 700; --lh-head: 1.05; --lh-body: 1.6;
  /* 움직임: 통통, 짧게 */
  --ease-pop: cubic-bezier(0.34, 1.56, 0.64, 1); --dur-1: 180ms; --dur-2: 500ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example vector-art` (구현할 때 한 번)

## 어울리는 모션
- 일러스트 선이 그려진다 (`signature-draw`)
- 일러스트 조각이 살짝 흔들리거나 떠 있다 (해, 구름, 잎)
- 카드 호버 때 일러스트만 살짝 커진다
- 강도: 낮음~중간

## 하지 말 것
- 무료 일러스트 팩의 얼굴 없는 사람
- 선 굵기가 여러 가지 (일러스트 3px, 아이콘 1.5px, 테두리 1px처럼 섞이면 다른 세계)
- 그라데이션과 3D 그림자
- 일러스트를 장식으로만 (그림이 내용을 설명해야 한다)
