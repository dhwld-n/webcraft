# minimalism

덜어낼 수 있는 것을 다 덜어낸 화면. 남은 것은 글자, 여백, 사진 한 장, 선 하나다. 빈 곳이 많아서 남은 요소 하나하나의 크기와 위치가 정확해야 한다. 비어 있는 게 아니라 **고른 것만 남은** 화면이다.

**어울리는 곳:** 건축·가구·패션 브랜드, 사진가·디자이너 포트폴리오, 고급 제품 한 가지, 갤러리, 핀테크(신뢰), 법률·컨설팅

**참고:** Raycash(따뜻하게 튼 미색 `#fefdf0` + 커피색 `#28211b`, 한 섹션에 제목 한 줄 + 설명 두 줄), daisyUI의 lofi·wireframe·silk 테마 토큰, Eric Jordan

## 뻔한 버전 (이렇게 나오면 실패)
- 흰 바탕 가운데 정렬 회색 제목 + 회색 설명 + 검정 버튼 하나. 아무 특징 없는 템플릿
- 여백만 늘리고 크기 대비가 없어서 모든 것이 같은 무게로 떠 있다
- 순백 `#ffffff` + 순검정 `#000000` + Inter 하나

## 레이아웃
- **비대칭 배치.** 가운데 정렬보다 12열 그리드에서 한쪽으로 치우친 배치가 긴장감을 준다 (제목 1~7열, 설명 9~12열)
- 섹션 위아래 여백을 크게 (120~200px). 대신 요소 사이 간격은 일정한 단위(8px 배수)로 맞춘다
- 한 화면에 주인공 하나. 사진 한 장이면 글은 작게, 큰 글이면 사진 없이
- 정보는 표나 정의 목록(라벨 + 값)으로 정리해 줄을 맞춘다

## 타이포
- 글꼴 하나 또는 둘. 산세리프 하나에 굵기 두 단계(400, 500~600)로 위계를 만든다
- **크기 대비를 극단적으로.** 큰 제목은 본문의 5~8배, 나머지는 거의 같은 크기. 중간 크기를 많이 만들지 않는다
- 작은 라벨: 12~13px, 대문자 영문이면 자간 0.06em. 한글 라벨에는 자간을 넣지 않는다
- 한글은 Pretendard, SUIT, 펴진고딕 같은 단정한 고딕. 세리프를 쓸 땐 마루부리 한 가지

## 색
- 바탕은 순백 대신 아주 살짝 튼 흰색 (따뜻: `#f7f5f0`, 차가운: `#f4f5f6`), 글자는 순검정 대신 `#1c1b19` 근처
- 회색 두 단계(보조 글자, 선)만 추가. 강조색은 없거나 한 가지를 아주 작게 (링크 밑줄, 점 하나)
- 사진이 있으면 사진이 유일한 색이다

## 질감
- 테두리 1px 선, 그림자 없음, 둥글기 0~4px
- 장식은 가는 선, 번호, 작은 점 정도

### 비슷한 스타일과 구별
- **스위스:** 그리드와 정보 구조가 주인공이고 굵은 산세리프 + 원색 하나를 쓴다. 미니멀은 비움과 고요함이 주인공이다
- **에디토리얼:** 긴 글, 세리프, 잡지 구조. 미니멀은 글이 짧다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 12열, 바깥 여백 넉넉하게 */
  --max: 1360px; --margin: clamp(20px, 5vw, 80px); --gap: clamp(16px, 2vw, 24px); --cols: 12;
  /* 여백 단위: 8px 배수. 섹션 사이는 크게 */
  --s-1: 8px; --s-2: 16px; --s-3: 24px; --s-4: 40px; --s-5: 64px; --section: clamp(96px, 14vw, 200px);
  /* 모양: 거의 각지게, 선 하나 */
  --r: 2px; --line: 1px solid color-mix(in srgb, var(--text) 14%, transparent);
  /* 글자 크기: 중간 단계 없이 작은 것과 아주 큰 것 */
  --fs-xs: 12px; --fs-sm: 14px; --fs-base: 16px; --fs-lg: 22px; --fs-hero: clamp(48px, 8.4vw, 132px);
  --fw-body: 400; --fw-head: 500; --lh-head: 0.98; --lh-body: 1.55; --ls-head: -0.035em;
  /* 움직임: 짧고 조용하게 */
  --ease: cubic-bezier(0.25, 0.1, 0.25, 1); --dur-1: 150ms; --dur-2: 600ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example minimalism` (구현할 때 한 번)

## 어울리는 모션
- 스크롤 등장은 투명도와 12px 정도 위로 (`scroll-reveal`, 약하게)
- 링크 밑줄이 그려지는 호버 (`hover-play` B)
- 첫 방문 로딩은 숫자 카운터 하나 (`smooth-loader`)
- 강도: 낮음. 움직임이 많으면 비움이 깨진다

## 하지 말 것
- 아이콘 줄 (기능 셋 + 아이콘 셋은 템플릿이다)
- 카드에 그림자, 둥근 모서리 16px 이상
- 회색 글자를 너무 연하게 (`#999` 이하는 대비 실패. `contrast.mjs`로 확인)
- 빈 곳을 채우려고 장식 추가하기. 비어 있는 게 디자인이다
