# bento-grid

도시락처럼 크기가 다른 칸들을 한 화면에 모아 정보를 한눈에 보여준다.

**어울리는 곳:** SaaS 기능 소개, 제품 스펙, 개인 소개 페이지, 대시보드형 랜딩

## 뻔한 버전 (이렇게 나오면 실패)
- 연회색 바탕 + 흰 둥근 칸 + 칸마다 작은 아이콘, 짧은 제목, 회색 설명 두 줄
- 칸 크기만 다르고 내용 구성은 전부 같음
- Inter, Geist 같은 흔한 고딕에 강조 칸 하나만 보라나 파랑

## 레이아웃
- 칸마다 내용의 종류가 달라야 한다 (큰 숫자 하나, 사진, 인용 한 줄, 작은 표, 움직이는 미니 화면)
- 4열 또는 6열 그리드, 칸 크기는 1x1, 2x1, 2x2를 섞는다
- 가장 중요한 내용 하나를 가장 큰 칸에
- 칸 사이 간격은 일정하게 (12~20px), 칸 안쪽 여백도 일정하게
- 모바일에서는 한 열로 쌓되, 큰 칸이 먼저 오게 순서를 정한다

## 타이포
- 깔끔한 산세리프. 흔한 Inter·Geist 대신 후보 목록에서 성격 있는 것 (한글 본문은 Pretendard도 괜찮다)
- 칸마다 짧은 제목 하나, 설명 한두 줄. 긴 글은 넣지 않는다
- 숫자는 크게 (지표, 가격)

## 색
- 배경과 칸의 명도 차이를 살짝 (밝은 회색 배경에 흰 칸, 또는 그 반대)
- 강조 칸 한두 개만 브랜드 색으로 채운다

## 질감
- 모서리 둥글게 (16~24px), 아주 옅은 테두리
- 칸 안에 작은 일러스트, 제품 화면 일부, 미니 차트

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 6열, 행 높이 고정. 칸은 1x1, 2x1, 2x2, 3x2를 섞는다 */
  --max: 1280px; --margin: clamp(16px, 4vw, 56px); --cols: 6; --row: clamp(150px, 15vw, 196px); --gap: 14px;
  /* 칸: 안쪽 여백 일정, 둥글기는 하나만 */
  --cell-pad: clamp(18px, 2vw, 28px); --radius: 22px; --radius-inner: 12px; /* 칸 안 요소 = 칸 둥글기 - 안쪽 여백의 절반 정도 */
  /* 글자 크기: 1.25배 단계. 칸 제목은 작게, 숫자는 아주 크게 */
  --fs-xs: 12px; --fs-sm: 14px; --fs-base: 16px; --fs-md: 20px; --fs-lg: 25px; --fs-xl: 32px;
  --fs-stat: clamp(56px, 7vw, 96px); --fs-hero: clamp(40px, 5.6vw, 80px);
  --lh-head: 1.1; --lh-body: 1.5; --track-stat: -0.04em; --track-head: -0.02em;
  /* 칸 색: 배경과 칸의 명도 차이는 작게 (4~6%), 강조 칸은 한두 개 */
  --cell: color-mix(in srgb, var(--surface) 100%, transparent); --cell-line: 1px solid color-mix(in srgb, var(--text) 8%, transparent);
  /* 움직임: 칸이 차례로, 짧게 */
  --ease: cubic-bezier(0.2, 0.9, 0.3, 1); --dur-1: 180ms; --dur-2: 420ms; --stagger: 60ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example bento-grid` (구현할 때 한 번)

## 어울리는 모션
- 칸이 순서대로 떠오르는 스크롤 등장
- 호버 시 칸이 살짝 커지거나 내용이 움직이는 마이크로 인터랙션
- 강도: 중간

## 하지 말 것
- 모든 칸을 같은 크기로 (그냥 카드 목록이 된다)
- 칸마다 다른 색, 다른 둥글기
- 칸 안에 버튼 여러 개
