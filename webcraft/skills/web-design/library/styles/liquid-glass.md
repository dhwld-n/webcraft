# liquid-glass

사진이나 색 있는 장면 위에 투명한 유리판 몇 장이 떠 있는 화면. 판은 뒤를 거의 그대로 비추고, 가장자리에 빛이 맺혀 경계가 보인다. 주인공은 유리가 아니라 **유리 너머의 장면**이다. 글래스모피즘이라고도 부른다.

**어울리는 곳:** 건축·인테리어·호텔, 여행, 날씨·지도 앱, 음악·영상 플레이어, 하드웨어 제품, 사진이 좋은 프리미엄 브랜드

**참고:** Fluid Glass(사진 위 반투명 알약 내비 하나), originkit·componentry의 유리 컴포넌트(재질 원리만). 코드와 이미지는 베끼지 않는다

## 뻔한 버전 (이렇게 나오면 실패)
- 보라·파랑 그라데이션 바탕에 흐린 원 두세 개 + 같은 크기의 반투명 카드 3개
- 카드, 버튼, 입력창, 내비까지 전부 유리 (판이 겹쳐 뿌옇고 무엇도 앞에 나오지 않는다)
- 단색 바탕 위의 유리 (비칠 게 없어 회색 판이 된다)
- 뒤가 안 보이게 뿌연 젖빛 판 + 흐릿한 회색 1px 선 (경계가 없고 투명하지도 않다)

## 레이아웃
- **장면이 먼저다.** 전체 화면 사진, 영상, 또는 색 면이 크게 깔리고, 유리는 그 위 1~3곳에만 놓는다 (고정 내비, 히어로 정보판, 재생 컨트롤 같은 곳)
- 유리판은 장면의 빈 곳(하늘, 벽, 물)에 둔다. 피사체를 가리지 않는다
- 장면 섹션과 평평한 섹션을 번갈아 둔다. 긴 글, 표, 가격은 불투명한 바탕에서 읽게 한다
- 모바일에서는 유리판을 화면 아래쪽 한 곳으로 모은다. 판이 화면 대부분을 덮으면 장면이 사라진다

## 타이포
- 정밀하고 가벼운 산세리프: 영문 Instrument Sans, Hanken Grotesk, General Sans, Switzer / 한글 Pretendard, SUIT, Wanted Sans
- 라벨과 수치는 모노스페이스를 작게 (Geist Mono, IBM Plex Mono). 유리판이 계기판처럼 보인다
- 큰 제목은 굵기 400~500, 자간 좁게. 굵은 제목은 유리의 가벼움과 싸운다
- 유리 위 글자는 15px 이상, 굵기 500 이상. 흐린 바탕 위의 가는 글자는 뭉개진다

## 색
- 장면의 색이 곧 팔레트다. 사진에서 2~3색을 뽑아 버튼과 강조에 쓴다
- 유리는 색이 거의 없다 (흰 기운 0.02~0.1). 밝은 섹션 위로도 지나가는 판(고정 내비)만 어두운 기운(`rgb(12 14 18 / 0.3~0.45)`)을 넣는다
- 평평한 섹션의 바탕은 장면과 같은 온도의 무채색 (따뜻한 미색, 차가운 회색)
- **대비는 뒤 장면의 가장 밝은 곳 기준**으로 `contrast.mjs`로 확인한다. 흐림 뒤의 색은 스크롤마다 바뀐다

## 질감
**유리는 투명하고, 경계가 보여야 한다.** 가운데는 뒤가 거의 그대로 비치고, 판이 있다는 건 가장자리로 안다. 뿌연 젖빛 판(흐림 16px 이상)은 유리가 아니라 반투명 플라스틱이다.

핵심은 네 가지다:
1. **흐림은 아주 약하게** (0~4px). 뒤 장면의 모양이 알아볼 수 있게 남는다
2. **면 색은 거의 없게.** 흰 기운 0.02~0.08을 비스듬한 그라데이션으로. 빛 받는 쪽만 살짝 밝다
3. **빛나는 테두리.** 위·왼쪽은 밝고 아래·오른쪽은 어두운 1.5px 그라데이션 테두리. 균일한 회색 1px 선이 아니다
4. **두께.** 안쪽 가장자리를 따라 옅은 빛(inset 그림자)을 둘러 판의 두께를 보인다

```css
.glass {
  position: relative;
  background: linear-gradient(135deg, rgb(255 255 255 / 0.1), rgb(255 255 255 / 0.02) 55%);
  -webkit-backdrop-filter: blur(3px) saturate(140%);
  backdrop-filter: blur(3px) saturate(140%);
  box-shadow:
    inset 0 0 20px rgb(255 255 255 / 0.12),  /* 두께: 가장자리 안쪽이 살짝 밝다 */
    inset 0 1px 0 rgb(255 255 255 / 0.45),   /* 위쪽 모서리에 맺힌 빛 */
    0 16px 40px rgb(0 0 0 / 0.18);           /* 장면에서 살짝 뜬다 */
}
.glass::after { /* 빛나는 테두리: 밝은 모서리 두 곳, 어두운 옆면 */
  content: ""; position: absolute; inset: 0; border-radius: inherit; padding: 1.5px; pointer-events: none;
  background: linear-gradient(135deg, rgb(255 255 255 / 0.9), rgb(255 255 255 / 0.15) 35%, rgb(255 255 255 / 0.05) 65%, rgb(255 255 255 / 0.6));
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude;
}
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .glass { background: rgb(18 20 26 / 0.7); } /* 흐림이 안 되는 브라우저: 글자를 읽을 수 있게 어둡게 */
}
```
- 투명한 유리 위 글자는 뒤 장면과 싸운다. 글자에 옅은 그림자(`text-shadow: 0 1px 12px rgb(0 0 0 / 0.35)`)를 주거나, 장면의 어두운 곳에 판을 둔다
- 읽을 것이 많은 판(정보판, 내비)만 흐림을 6~10px까지 올린다. 그래도 테두리는 그대로 둔다
- 커서를 따라 움직이는 반사광은 `liquid-glass` 레시피에 있다 (`::before`를 쓰므로 테두리 `::after`와 겹치지 않는다)
- **굴절:** 가장자리에서 뒤 장면이 휘게 하려면 `glass-refraction` 레시피를 판에 `data-refract`로 붙인다. 판 1~3개에만. 굴절이 없는 브라우저를 위해 위의 흐림과 테두리는 그대로 둔다

### 비슷한 스타일과 구별
- **클레이모피즘:** 불투명 무광 파스텔, 색 물든 안쪽 그림자로 통통함. 유리는 투명하고 뒤가 비친다
- **다크테크:** 어두운 단색 바탕 위의 선과 빛. 유리는 비칠 장면이 있어야 성립한다
- **애플 리퀴드 글래스(iOS 26):** 가장자리에서 뒤가 렌즈처럼 휜다. 웹에서는 `glass-refraction` 레시피(SVG 변위 필터)로 넣는다. 크롬 계열에서만 휘고, 나머지 브라우저는 흐림과 테두리로 보인다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 장면은 화면 끝까지, 글은 좁게 */
  --max: 1280px; --margin: clamp(16px, 4vw, 48px); --gap: clamp(16px, 2.4vw, 32px);
  /* 둥글기: 판은 크게, 내비와 버튼은 알약 */
  --r-sm: 12px; --r-md: 22px; --r-lg: 32px; --r-pill: 999px; --pad: clamp(18px, 2.4vw, 32px);
  /* 유리: 투명한 판 + 빛나는 테두리 (질감 참고). 흐림은 약하게, 읽을 판만 --glass-blur-read */
  --glass-bg: linear-gradient(135deg, rgb(255 255 255 / 0.1), rgb(255 255 255 / 0.02) 55%);
  --glass-rim: linear-gradient(135deg, rgb(255 255 255 / 0.9), rgb(255 255 255 / 0.15) 35%, rgb(255 255 255 / 0.05) 65%, rgb(255 255 255 / 0.6));
  --glass-blur: 3px; --glass-blur-read: 8px; --glass-fallback: rgb(18 20 26 / 0.7);
  --glass-shadow: inset 0 0 20px rgb(255 255 255 / 0.12), inset 0 1px 0 rgb(255 255 255 / 0.45), 0 16px 40px rgb(0 0 0 / 0.18);
  --glass-text-shadow: 0 1px 12px rgb(0 0 0 / 0.35);
  /* 글자 크기: 1.333배 단계. 제목은 가볍게 */
  --fs-xs: 12px; --fs-sm: 15px; --fs-base: 17px; --fs-md: 22px; --fs-lg: 30px; --fs-xl: 40px; --fs-hero: clamp(42px, 6.4vw, 92px);
  --fw-body: 400; --fw-glass: 500; --fw-head: 400; --lh-head: 1.02; --lh-body: 1.5; --ls-head: -0.03em; --ls-label: 0.08em;
  /* 움직임: 미끄러지듯 조용히 */
  --ease: cubic-bezier(0.22, 1, 0.36, 1); --dur-1: 200ms; --dur-2: 500ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example liquid-glass` (구현할 때 한 번)

## 어울리는 모션
- 판 가장자리에서 뒤가 휘는 굴절 (`glass-refraction` 레시피). 움직이는 장면 위에서 가장 잘 보인다
- 커서를 따라 판 위 반사광이 움직인다 (`liquid-glass` 레시피). 판 하나에만
- 장면이 스크롤에 맞춰 천천히 커지거나 움직이고, 유리판은 제자리에 있다. 움직이는 장면 위 고정된 판이 유리를 가장 유리답게 보이게 한다
- 버튼은 살짝 끌려오는 정도 (`magnetic-button`, 약하게)
- 강도: 낮음~중간. 튀거나 흔들리는 움직임은 어울리지 않는다

## 하지 말 것
- 유리판을 4곳 이상 (뿌옇고 성능도 떨어진다. `backdrop-filter`는 판마다 뒤를 매 프레임 다시 그린다)
- 화면 절반 넘게 덮는 큰 유리판
- 유리 안에 유리 (흐림이 겹쳐 뭉개진다)
- 흐림 없는 브라우저 대체 없이 쓰기 (`@supports not` 필수)
- 장식용 흐린 원(블롭)을 깔아 비칠 것을 만들기. 비칠 장면은 사진이나 콘텐츠여야 한다
- 긴 본문, 표, 폼을 유리 위에
