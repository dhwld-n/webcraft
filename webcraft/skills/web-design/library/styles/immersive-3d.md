# immersive-3d

화면 전체가 3D 장면이거나, 3D 물체 하나가 내용을 담는다. 웹페이지를 읽는 게 아니라 어떤 장소에 들어가거나 물건을 만지는 느낌.

**어울리는 곳:** 크리에이티브 개발자·스튜디오 포트폴리오, 문화 콘텐츠 카탈로그(영화, 음반, 책), 제품 런칭, 전시, 브랜드 캠페인

## 뻔한 버전 (이렇게 나오면 실패)
- 가운데에 와이어프레임 정이십면체나 토러스 매듭이 돌고, 네 모서리에 영문 모노 대문자 계기판, 강조색은 라임이나 시안
- 3D 물체가 내용과 아무 상관이 없다 (지워도 사이트가 똑같다)
- 3D 위에 평범한 랜딩 페이지(큰 제목, 설명, 버튼)를 그대로 얹었다

## 먼저 정할 것: 3D가 왜 있는가
둘 중 하나를 고르고 방향 확인 때 사용자에게 보여 준다.
- **물건 하나 (은유):** 내용을 상징하는 물건을 정한다. 음반이면 레코드, 책방이면 책, 공연이면 티켓, 사진가면 필름 통. 단순한 도형에 **실제 이미지 텍스처**를 입히면 적은 코드로 물성이 생긴다 (`object-shelf`)
- **장소나 형태 (분위기):** 입자, 안개, 빛으로 공간을 만든다. 내용과 이어지는 형태(이름 글자, 로고, 제품 윤곽)가 입자로 모였다 흩어진다 (`point-morph`)
- 진짜 건물이나 숲 같은 장면은 사람이 3D 도구로 만든 에셋이 필요하다. 사용자가 `.glb` 파일을 주거나, 무료 CC0 모델(Poly Haven, Kenney, Quaternius)을 쓸 때만 고른다. 없으면 위 둘 중 하나로 간다

## 레이아웃
- 3D에 화면을 양보한다. 글자는 가장자리에 작게, 또는 한 곳에만 크게
- **내용은 진짜 HTML로 둔다.** 프로젝트 목록, 링크, 설명은 DOM에 있고, 3D는 그것을 비춘다. 그래야 검색, 키보드, 스크린 리더, WebGL이 없는 기기에서도 읽힌다
- 스크롤이 탐색이 된다: 스크롤하면 카메라가 움직이거나 물건이 줄지어 흐른다
- 무거운 장면이면 입장 의식(`hold-to-enter`)으로 로딩을 경험으로 바꾼다

## 타이포
- 장면과 부딪히지 않는 가는 그로테스크나 대비 큰 세리프. 글자 수를 줄인다
- 숫자(좌표, 시각, 퍼센트)를 살아 있게 보여 주면 계기판 느낌이 난다. 라벨은 한글이나 소문자로 써서 흔한 영문 대문자 HUD를 피한다

## 색
- 배경 한 가지 (아주 어둡거나 아주 밝게). 밝은 배경도 좋다
- 색은 대부분 텍스처나 빛에서 오게 하고, UI 강조색은 하나만 아주 작게

## 질감
- 후처리로 공기를 만든다: 안개, 약한 빛 번짐(bloom), 필름 노이즈 (`three-stage`)
- 반사가 있는 재질(MeshPhysicalMaterial + 환경광)이 플라스틱 같은 단색보다 훨씬 고급스럽다

## 수치 토큰
값은 출발점이다. 3D 장면 자체의 값(안개, 빛 번짐, 카메라)은 `three-stage` 레시피의 조절값을 쓰고, 여기는 장면 위 HTML의 값이다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 장면 위 글자의 바깥 여백. 어디에 둘지는 구도 스케치가 정한다 */
  --edge: clamp(16px, 2.4vw, 36px); --edge-gap: 6px;
  /* 글자 크기: 아주 작은 것과 아주 큰 것만. 중간 크기를 거의 쓰지 않는다 */
  --fs-micro: 11px; --fs-sm: 13px; --fs-base: 15px; --fs-title: clamp(40px, 7vw, 120px);
  --lh-title: 0.92; --lh-body: 1.5; --track-title: -0.03em;
  /* 층: 장면 0, 장면 위 글자 1, 입장 화면 10 */
  --z-scene: 0; --z-ui: 1; --z-gate: 10;
  /* 선: 진행 막대와 프레임만 */
  --line: 1px solid color-mix(in srgb, var(--text) 30%, transparent); --progress-h: 2px;
  /* 움직임: 장면 위 글자는 짧게 바뀌고, 장면은 길게 흐른다 */
  --ease: cubic-bezier(0.16, 1, 0.3, 1); --dur-ui: 280ms; --dur-title: 700ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example immersive-3d` (구현할 때 한 번)

## 어울리는 모션
- 커서에 따라 카메라나 물체가 아주 조금 기운다 (과하면 멀미)
- 스크롤에 관성을 준다 (값을 바로 쓰지 않고 따라가게)
- 글자 섞임으로 시작하는 문구 (`scramble-text`), 페이지 사이 이어지는 전환 (`view-transition`)
- 강도: 높음. 대신 주인공은 3D 하나

## 하지 말 것
- 위 "뻔한 버전"
- 캔버스 여러 개. 장면은 하나로
- 모션 줄이기 설정을 무시한 자동 회전, 카메라 흔들림
- WebGL이 없을 때 빈 화면 (대체 이미지와 HTML 목록이 보여야 한다)
- 에셋 3MB 이상, 기기 픽셀 비율 2 초과 렌더링
