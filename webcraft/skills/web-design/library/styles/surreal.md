# surreal

꿈속 같은 화면. 있을 수 없는 크기, 떠 있는 물건, 잘못된 그림자, 하늘 한가운데 문. 익숙한 것을 낯선 자리에 두어 "어?" 하고 멈추게 만든다. 이상하지만 고요하고, 장면 하나하나가 그림처럼 정성스럽다.

**어울리는 곳:** 예술가·일러스트레이터 포트폴리오, 음반·뮤직비디오, 패션 캠페인, 향수, 미술관 전시, 실험적 브랜드

**참고:** A24 Discs(물건을 수집품처럼 띄워 둔 고요함), Bricelab(낯선 공간에 들어가는 의식), Warm and Fuzzy

## 뻔한 버전 (이렇게 나오면 실패)
- AI 이미지 생성기로 만든 "초현실" 배경 한 장 + 그 위에 평범한 랜딩 레이아웃
- 녹아내리는 시계, 떠 있는 바위 섬 같은 유명한 초현실 그림 흉내
- 이상한 것만 잔뜩 있고 고요함이 없다

## 레이아웃
- **장면 하나에 이상한 것 하나.** 평범한 구도 속 한 요소만 크기, 위치, 중력이 틀린다
- 넓은 빈 공간 (하늘, 바닥, 벽)이 이상한 물건을 돋보이게 한다
- 글은 작고 조용하게, 장면의 구석에. 제목이 물건처럼 공간에 놓일 수도 있다 (원근을 따라 눕거나 그림자를 드리운다)
- 스크롤이 장면을 넘기는 이야기가 된다 (한 화면 = 한 장면)

## 타이포
- 우아한 고대비 세리프나 독특한 디스플레이 한 가지 (Fraunces, Gloock, Syne / 한글 Moirai One, Diphylleia, 마루부리)
- 본문은 작은 산세리프, 아주 절제
- 글자에 그림자를 드리워 공간에 놓인 것처럼 (그림자 방향은 장면의 빛과 맞춘다)

## 색
- 장면의 색은 2~3가지로 단순하게, 채도 낮은 꿈 색 (분홍 하늘 `#f2c6c2` + 깊은 파랑 `#1f3a6b` + 모래 `#e6d3b3`)
- 하나의 이상한 물건만 강한 색 (빨강 `#d62828` 같은)
- 그림자는 장면 색의 진한 톤. 검정 그림자 없음

## 질감
- 부드러운 그라데이션 하늘, 긴 그림자, 옅은 그레인
- 사진 합성이면 빛 방향을 맞춘다. 오린 가장자리를 숨긴다

### 비슷한 스타일과 구별
- **콜라주:** 오린 가장자리를 일부러 보여 준다. 초현실은 이어 붙인 흔적을 숨기고 "진짜처럼" 이상하다
- **이머시브 3D:** 기술로 공간을 만든다. 초현실은 이미지의 논리를 비튼다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  --max: 1280px; --margin: clamp(20px, 5vw, 72px); --gap: clamp(16px, 2.4vw, 32px);
  /* 꿈 장면 */
  --sky-top: #f2c6c2; --sky-bottom: #f8e7d8; --ground: #e6d3b3; --odd: #d62828;
  --shadow-long: 60px 70px 40px rgb(31 58 107 / 0.28);
  /* 글자 */
  --fs-sm: 13px; --fs-base: 16px; --fs-lg: 24px; --fs-hero: clamp(48px, 8vw, 128px);
  --fw-body: 400; --fw-head: 400; --lh-head: 0.95; --lh-body: 1.6; --ls-head: -0.02em;
  /* 움직임: 둥실, 아주 느리게 */
  --ease: cubic-bezier(0.37, 0, 0.63, 1); --float: 9s; --dur-2: 1200ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example surreal` (구현할 때 한 번)

## 어울리는 모션
- 이상한 물건이 천천히 둥실 떠 있다 (9초 주기, 몇 px만)
- 스크롤에 따라 장면 조각이 서로 다른 속도로 (`parallax-layers`)
- 장면이 바뀔 때 천천히 녹아드는 전환 (`view-transition`, 900ms 이상)
- 강도: 낮음. 빠르면 꿈이 깨진다

## 하지 말 것
- 유명 초현실 작품의 모티프 그대로 (녹는 시계, 사과 얼굴, 중절모)
- AI 생성 이미지 배경에 의존 (흔하고 티가 난다. 직접 만든 단순한 장면이 낫다)
- 이상한 것을 화면마다 여러 개
- 글을 많이 (설명하면 마법이 사라진다)
