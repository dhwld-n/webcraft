# maximalism

많을수록 좋다. 큰 글자, 여러 서체, 강한 색, 겹친 사진, 무늬, 움직이는 띠가 한 화면에 모인다. 하지만 **아무렇게나 많은 게 아니다.** 반복되는 규칙(같은 색 셋, 같은 각도, 같은 크기 단계)이 있어서 시끄러워도 하나로 읽힌다.

**어울리는 곳:** 음악·공연·축제, 패션·뷰티, 음료·간식 브랜드, 크리에이티브 에이전시, 굿즈 숍, 문화 행사

**참고:** Lando Norris, Monument, Warm and Fuzzy, Royal Beverage, Red Antler, ilovecreatives(문장 안에 세리프 단어·작은 사진·알약 단어를 끼운 한 줄 콜라주), daisyUI acid 테마 토큰

## 뻔한 버전 (이렇게 나오면 실패)
- 무지개 그라데이션 바탕 + 굵은 흰 글자 + 이모지 스티커 (색만 많고 규칙이 없다)
- 요소는 많은데 크기가 다 비슷해서 주인공이 없다
- 카드 그리드에 색만 진하게 칠한 것 (구조는 평범한 템플릿 그대로)

## 레이아웃
- **화면 폭을 넘는 큰 글자.** 제목이 화면 밖으로 잘리거나 두 줄이 겹친다
- 겹침: 사진 위에 글자, 글자 위에 스티커, 띠 위에 띠. 레이어가 3층 이상
- 섹션마다 바탕색이 바뀐다 (팔레트 3~4색을 돌아가며)
- 리듬을 위해 빽빽한 섹션 다음에는 큰 글자 한 줄만 있는 섹션을 둔다

## 타이포
- 서체 2~3개를 섞는다: 굵은 디스플레이(콘덴스드나 블랙) + 고전 세리프 이탤릭 + 작은 모노나 그로테스크
- 한 문장 안에 서체를 바꿔 끼운다 (ilovecreatives처럼 강조 단어만 세리프)
- 제목 크기: 본문의 8~15배, 행간 0.85~0.95
- 한글: 굵은 디스플레이(Black Han Sans, 을지로체, Gasoek One)와 명조 한 가지를 섞는다

## 색
- 강한 색 3~4개로 팔레트를 정하고 그 안에서만 쓴다 (예: 토마토 `#ff4a1c` + 라임 `#c8ff3d` + 진보라 `#3b1d6e` + 크림 `#fff4e0`)
- 색 면 위의 글자는 팔레트 안의 다른 색. 대비는 하나하나 확인한다
- 사진은 원색으로 덮거나(듀오톤) 오려서 색 면 위에 올린다

## 질감
- 무늬: 체크, 줄무늬, 물방울, 반복 로고
- 스티커처럼 오린 사진에 흰 테두리 4~8px
- 그레인(`grain-gradient`)을 살짝 깔면 디지털 느낌이 덜하다

### 비슷한 스타일과 구별
- **팝아트:** 만화 망점, 굵은 윤곽선, 말풍선. 맥시멀은 특정 화법 없이 많음 자체
- **콜라주:** 오리고 붙인 종이 질감이 핵심. 맥시멀은 디지털이어도 된다
- **네오 브루탈리즘:** 두꺼운 테두리와 그림자 규칙 하나. 맥시멀은 규칙이 여러 개 겹친다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 넘쳐도 되는 바깥 여백 */
  --max: 1600px; --margin: clamp(12px, 3vw, 40px); --gap: clamp(10px, 1.6vw, 24px);
  /* 크기: 극단적으로 큰 제목 */
  --fs-sm: 14px; --fs-base: 17px; --fs-lg: clamp(28px, 3.4vw, 52px); --fs-xl: clamp(48px, 7vw, 120px); --fs-hero: clamp(72px, 17vw, 280px);
  --fw-body: 500; --fw-head: 900; --lh-head: 0.86; --lh-body: 1.4; --ls-head: -0.04em;
  /* 모양: 스티커와 띠 */
  --r-sticker: 999px; --sticker-edge: 6px solid #fff; --tilt-1: -4deg; --tilt-2: 3deg;
  /* 움직임: 빠르고 통통 튄다 */
  --ease-pop: cubic-bezier(0.34, 1.56, 0.64, 1); --dur-1: 180ms; --dur-2: 520ms; --marquee: 22s;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example maximalism` (구현할 때 한 번)

## 어울리는 모션
- 서로 다른 속도로 흐르는 큰 글자 띠 여러 줄 (`marquee`)
- 글자가 튀어 오르는 등장 (`kinetic-headline`)
- 겹친 조각이 서로 다른 속도로 지나가는 스크롤 (`parallax-layers`)
- 목록 호버 때 사진이 커서를 따라 나온다 (`hover-play` A)
- 강도: 높음. 다만 움직이는 것 3종 이하

## 하지 말 것
- 팔레트 밖의 색을 "하나만 더" 추가하기
- 모든 요소를 같은 크기로 (주인공이 없으면 그냥 어지럽다)
- 긴 본문을 색 면 위 작은 글자로 (읽을 글은 크림 바탕에서)
- 움직임을 다섯 종류 이상 (멀미)
