# editorial

잡지를 펼친 느낌. 글이 주인공이고, 여백과 타이포 위계로 리듬을 만든다.

**어울리는 곳:** 브랜드 스토리, 매거진, 카페·레스토랑, 패션, 출판, 포트폴리오

## 뻔한 버전 (이렇게 나오면 실패)
- 미색 바탕 + 화면 가운데 큰 명조 제목 + 그 위 작은 자간 넓은 라벨 + 아래 짧은 설명 두 줄
- Playfair Display, Fraunces, Cormorant, Instrument Serif 같은 흔한 세리프 제목
- 모든 섹션이 가운데 정렬 한 단, 얇은 선과 넉넉한 여백만 반복

## 레이아웃
- 첫 화면부터 비대칭. 제목을 왼쪽이나 아래쪽에 크게 걸치고, 사진이나 긴 캡션이 나머지를 채운다
- 12열 그리드에 일부러 비대칭 배치. 본문은 6~7열, 나머지는 여백이나 캡션
- 큰 제목과 작은 본문의 크기 차이를 크게 (예: 96px 대 18px)
- 섹션 사이 여백을 넉넉하게 (데스크톱 160px 이상)
- 사진은 화면 가장자리까지 꽉 채우거나, 본문 폭 안에 작게. 어중간한 크기는 피한다

## 타이포
- 제목: 대비가 강한 세리프. 후보 목록에서 흔하지 않은 것 (한글은 명조 계열 눈누 폰트도 좋다)
- 본문: 차분한 세리프나 산세리프, 줄 길이 60~75자, 행간 1.6~1.8
- 이탤릭과 작은 대문자로 강조
- 숫자, 날짜, 장 번호 같은 작은 장식 요소를 활용

## 색
- 종이 같은 배경, 거의 검은 잉크색 글자. 미색·아이보리는 너무 흔하니 회색 종이, 신문지, 차가운 흰색, 짙은 바탕에 밝은 글자도 고려한다
- 강조색은 하나만, 아주 아껴서

## 질감
- 얇은 구분선 (1px), 그림자 없음
- 사진에 약한 필름 그레인 정도는 괜찮다

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 12열, 넓은 바깥 여백. 본문은 가운데가 아니라 4~9열 */
  --max: 1440px; --margin: clamp(20px, 6vw, 104px); --gutter: 28px;
  /* 글자 크기: 1.5배 단계. 본문은 크게(19px), 제목은 본문의 8배 이상 */
  --fs-cap: 13px; --fs-sm: 15px; --fs-base: 19px; --fs-md: 24px; --fs-lg: 34px; --fs-xl: 52px;
  --fs-quote: clamp(32px, 4.4vw, 68px); --fs-hero: clamp(60px, 11vw, 184px); --fs-drop: 5.2em;
  --lh-hero: 0.9; --lh-head: 1.05; --lh-body: 1.72; --measure: 31em;
  --track-hero: -0.03em; --track-caps: 0.08em;
  /* 여백: 섹션 사이는 아주 넓게, 문단 사이는 행간 하나 */
  --s-1: 8px; --s-2: 16px; --s-3: 28px; --s-4: 48px; --s-5: 80px; --section: clamp(128px, 17vw, 260px);
  /* 선: 가는 괘선만. 그림자와 둥글기 없음 */
  --rule: 1px solid color-mix(in srgb, var(--text) 22%, transparent); --rule-strong: 2px solid var(--text); --radius: 0;
  /* 움직임: 느리고 조용하게 */
  --ease: cubic-bezier(0.22, 1, 0.36, 1); --dur-1: 240ms; --dur-2: 600ms; --dur-3: 1100ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example editorial` (구현할 때 한 번)

## 어울리는 모션
- 절제된 것만. 섹션이 천천히 떠오르는 스크롤 등장, 제목 글자 단위 등장 정도
- 강도: 낮음

- 화면마다 다른 강조색
- 빠르고 튀는 애니메이션
