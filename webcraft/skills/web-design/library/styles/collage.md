# collage

잡지에서 오리고 테이프로 붙인 스크랩북. 찢긴 종이 가장자리, 비뚤게 붙은 사진, 마스킹 테이프, 손글씨 메모, 다른 서체를 오려 붙인 글자. 손때와 우연이 개성이 된다.

**어울리는 곳:** 크리에이터·예술가 포트폴리오, 독립 출판·잡지, 패션·빈티지, 음악·공연 포스터, 문화 공간, 교육 커뮤니티

**참고:** ilovecreatives(문장 안에 세리프 단어·작은 사진·알약 단어를 끼운 한 줄 콜라주, 필름 사진, 흑백 바탕), Warm and Fuzzy, daisyUI cmyk 테마 토큰

## 뻔한 버전 (이렇게 나오면 실패)
- 정돈된 카드 그리드에 사진을 몇 도씩 돌려 놓기만 (그냥 기운 카드)
- 찢긴 종이 PNG를 모든 사진 테두리에 똑같이
- 손글씨 글꼴을 본문에

## 레이아웃
- **겹침과 비뚤어짐.** 사진·종이·메모가 3~6° 범위에서 서로 다른 각도로 겹친다. 같은 각도 두 번 쓰지 않는다
- 그리드는 보이지 않게 있다. 조각들의 중심이 그리드 칸에 대략 맞아서 엉망이 되지 않는다
- 큰 문장 안에 작은 사진, 다른 서체 단어, 알약 테두리 단어를 끼운다 (ilovecreatives 방식)
- 흰 여백을 넉넉히. 콜라주 조각은 한 장면에 4~7개

## 타이포
- 서체 섞기가 핵심: 굵은 그로테스크 + 고전 세리프 이탤릭 + 타자기 모노 + 손글씨 메모 (영문 Archivo Black, Playfair Display, Space Grotesk, Caveat / 한글 Black Han Sans, 고운바탕, 메모먼트꾹꾹체)
- 오린 글자: 단어마다 다른 바탕 종이(흰색, 신문지 회색, 노랑)와 다른 서체로 랜섬 노트처럼. 제목 한 줄에만
- 본문은 평범한 고딕이나 세리프 하나로 조용하게

## 색
- 바탕: 흰 종이 `#faf8f3` 또는 크라프트지 `#d9c4a0`
- 조각의 색: 사진 색 + 종이 2~3색(신문지 `#e9e6df`, 노랑 메모지 `#ffe76a`, 파랑 줄 공책 `#d6e4f0`)
- 강조 하나: 빨간 펜 `#e0322b` 동그라미나 밑줄

## 질감
- 찢긴 가장자리: `clip-path: polygon(...)`에 불규칙한 점 10~16개, 또는 SVG 마스크
- 마스킹 테이프: 반투명 노랑 사각형 (`rgb(255 230 150 / 0.75)`), 양 끝을 톱니로
- 종이 그림자: 아주 얕고 가까운 그림자 (`0 2px 3px rgb(0 0 0 / 0.18)`)
- 사진: 흑백이나 바랜 필름, 일부만 컬러

### 비슷한 스타일과 구별
- **맥시멀리즘:** 디지털이어도 되는 "많음". 콜라주는 종이와 손의 흔적
- **초현실:** 이어 붙인 흔적을 숨긴다. 콜라주는 일부러 보여 준다
- **손글씨:** 손으로 쓴 선과 낙서가 주인공. 콜라주는 오려 붙인 조각이 주인공

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  --max: 1320px; --margin: clamp(16px, 4vw, 56px); --gap: clamp(14px, 2vw, 28px);
  --paper: #faf8f3; --news: #e9e6df; --memo: #ffe76a; --pen: #e0322b;
  /* 조각 각도: 같은 값 두 번 쓰지 않는다 */
  --t1: -4deg; --t2: 3deg; --t3: -2deg; --t4: 5deg; --t5: -6deg;
  /* 종이 */
  --paper-shadow: 0 2px 3px rgb(0 0 0 / 0.18), 0 10px 24px -12px rgb(0 0 0 / 0.25);
  --tape: rgb(255 230 150 / 0.75);
  --torn: polygon(0 3%, 9% 0, 22% 2%, 37% 0, 51% 3%, 66% 0, 80% 2%, 100% 0, 98% 30%, 100% 62%, 97% 100%, 74% 97%, 52% 100%, 31% 96%, 12% 100%, 0 97%, 2% 60%, 0 28%);
  /* 글자 */
  --fs-sm: 14px; --fs-base: 17px; --fs-lg: clamp(22px, 2.6vw, 34px); --fs-hero: clamp(48px, 8vw, 120px);
  --fw-body: 400; --fw-head: 800; --lh-head: 1.0; --lh-body: 1.6;
  /* 움직임: 종이가 툭 놓인다 */
  --ease-drop: cubic-bezier(0.34, 1.3, 0.64, 1); --dur-2: 600ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example collage` (구현할 때 한 번)

## 어울리는 모션
- 스크롤하면 조각이 하나씩 툭 놓인다 (위에서 살짝 떨어지며 각도 자리 잡기)
- 조각들이 서로 다른 속도로 지나간다 (`parallax-layers`)
- 목록 호버 때 사진 조각이 커서를 따라 나온다 (`hover-play` A)
- 빨간 펜 동그라미가 그려진다 (`signature-draw`)
- 강도: 중간

## 하지 말 것
- 모든 조각을 같은 각도로, 같은 찢긴 모양으로
- 랜섬 노트 글자를 본문이나 버튼에 (읽기 어렵다)
- 진한 종이 텍스처 이미지를 화면 전체에
- 조각 10개 이상을 한 화면에
