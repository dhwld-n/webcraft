# retro-pixel

8비트·16비트 게임의 도트 세계. 화면의 모든 것이 정사각형 픽셀 단위로 맞춰지고, 색은 정해진 팔레트 몇 개뿐이다. 계단처럼 각진 테두리, 깜빡이는 커서, 대화 상자. 귀엽고 정직하다.

**어울리는 곳:** 인디 게임, 게임 굿즈, 개발자 개인 사이트, 레트로 음악, 장난스러운 앱, 행사 이벤트 페이지

**참고:** Poolsuite(레트로 OS와 컴퓨터 감성), Componentry(픽셀 컴포넌트)

## 뻔한 버전 (이렇게 나오면 실패)
- 평범한 랜딩에 Press Start 2P 글꼴만 바꿔 넣기 (본문까지 픽셀 글꼴이라 읽기 힘들다)
- 매끈한 둥근 카드 + 그라데이션 + 픽셀 글꼴 (도트 세계가 아니다)
- 이미지가 흐릿하게 늘어난다 (`image-rendering` 안 씀)

## 레이아웃
- **픽셀 단위 격자.** 모든 크기를 기본 픽셀(4px 또는 8px)의 배수로. 테두리도 4px 계단
- 게임 화면처럼: 위에 상태 막대(점수, 목숨), 가운데 장면, 아래 대화 상자
- 정보 상자는 RPG 대화창 모양 (두꺼운 테두리 + 안쪽 테두리 한 겹)
- 메뉴는 ▶ 커서가 붙는 선택지 목록

## 타이포
- 제목과 라벨: 픽셀 글꼴 (Press Start 2P, Silkscreen, Pixelify Sans, DotGothic16 / 한글 둥근모꼴, Galmuri 계열, Mona12)
- **본문은 읽기 쉬운 글꼴로.** 픽셀 본문은 짧은 문장에만. 긴 글은 고딕 본문(Pretendard) 16px
- 픽셀 글꼴은 원래 크기의 정수배로만 (8px 글꼴이면 16, 24, 32px). 아니면 뭉개진다

## 색
- 팔레트 4~8색 고정 (예: 게임보이 계열 `#0f380f` `#306230` `#8bac0f` `#9bbc0f`, 또는 밤 `#1a1c2c` + 분홍 `#ef7d57` + 노랑 `#ffcd75` + 하늘 `#41a6f6`)
- 그라데이션 금지. 음영은 디더링(점 무늬)이나 한 단계 진한 색으로

## 질감
픽셀 테두리는 `box-shadow` 여러 겹으로 계단을 만든다.

```css
.px-box {
  background: var(--px-2); color: var(--px-4);
  box-shadow: 0 -4px 0 0 var(--px-0), 0 4px 0 0 var(--px-0), -4px 0 0 0 var(--px-0), 4px 0 0 0 var(--px-0),
              inset 0 -4px 0 0 var(--px-1);   /* 바깥 계단 테두리 + 아래쪽 안 그림자 */
  image-rendering: pixelated;
}
img.px { image-rendering: pixelated; }      /* 작은 도트 그림을 키워도 선명하게 */
```

### 비슷한 스타일과 구별
- **Y2K:** 매끈한 크롬과 광택. 픽셀은 각지고 평평하다
- **레트로:** 70~90년대 인쇄물, 간판의 따뜻함. 픽셀은 게임 화면

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 기본 픽셀: 모든 크기는 이 배수 */
  --px: 4px; --max: 1200px; --margin: calc(var(--px) * 6); --gap: calc(var(--px) * 4);
  /* 팔레트 4색 (0 진함 → 4 밝음) */
  --px-0: #1a1c2c; --px-1: #333c57; --px-2: #f4f4f4; --px-3: #ffcd75; --px-4: #1a1c2c; --px-hi: #ef7d57;
  /* 글자: 픽셀 글꼴은 정수배 */
  --fs-pixel-sm: 8px; --fs-pixel: 16px; --fs-pixel-lg: 32px; --fs-hero: 48px; --fs-base: 16px;
  --lh-head: 1.25; --lh-body: 1.6;
  /* 움직임: 계단식 */
  --ease: steps(4, end); --blink: 1s; --dur-1: 120ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example retro-pixel` (구현할 때 한 번)

## 어울리는 모션
- 깜빡이는 ▶ 커서, 한 글자씩 찍히는 대화 (`steps()` 타이핑)
- 픽셀 로딩 막대 (`pixel-loader`)
- 버튼을 누르면 4px 아래로 내려가고 그림자가 사라진다
- 움직임은 모두 `steps()`로. 부드러운 곡선은 도트 세계와 안 맞는다

## 하지 말 것
- 본문 전체를 픽셀 글꼴로
- 그라데이션, 흐림, 둥근 모서리
- 픽셀 글꼴을 정수배가 아닌 크기로 (13px, 18px)
- 팔레트 밖 색
