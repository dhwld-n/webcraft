# dark-tech

어두운 배경에 정밀한 선과 숫자. 기계나 계측 장비를 들여다보는 느낌. 개발자 도구와 AI 제품에서 많이 쓰여서 **가장 쉽게 뻔해지는 스타일**이다. 아래 "뻔한 버전"부터 읽는다.

**어울리는 곳:** 개발자 도구, AI·인프라 제품, 보안, 핀테크, 테크 스타트업

## 뻔한 버전 (이렇게 나오면 실패)
- 알약 배지 → 가운데 두 줄 제목(둘째 줄만 흐리거나 강조색) → 설명 → 버튼 두 개나 이메일 칸 → 그 아래 기울인 제품 화면
- 남색·보랏빛 검정 + 격자나 점 배경 + 히어로 뒤 파란 빛 번짐 + 라임·형광 노랑 알약 버튼
- 섹션마다 영문 대문자 모노 라벨, "01 / 02 / 03" 번호 줄 + 태그 칩
- 제목과 본문이 Inter, Geist, Space Grotesk, Manrope 같은 흔한 그로테스크

## 레이아웃
- 히어로는 **왼쪽 정렬이나 비대칭**. 제목이 화면 한쪽을 크게 차지하고, 다른 쪽에 실제 값이 움직이는 무언가(로그, 그래프, 수치 한 개)를 둔다
- 제품 화면을 보여줄 거면 통째로 기울인 창 대신, 가장 중요한 한 부분만 크게 잘라서 보여준다
- 선은 격자를 깔기보다 정보를 나누는 데만 쓴다 (표의 행, 눈금, 축)
- 섹션마다 구성이 달라야 한다. 표, 큰 숫자 하나, 긴 로그, 짧은 문장처럼 내용에 맞는 틀을 고른다

## 타이포
- 제목: 폭이 넓거나 좁은 그로테스크, 기계적인 디스플레이, 또는 대비를 주는 세리프. 후보 목록에서 흔하지 않은 것을 고른다
- 숫자와 데이터에만 모노스페이스. 라벨까지 전부 모노 대문자로 만들지 않는다
- 제목은 한 가지 색. 강조가 필요하면 굵기나 크기로

## 색
- 배경은 검정 계열이면 되지만 기본값처럼 보이는 남색 검정만 고집하지 않는다 (먹색, 올리브 검정, 갈색 검정, 아주 어두운 회녹색도 된다)
- 글자는 밝은 회색 위계 (100%, 64%, 42%. 아래 토큰)
- 강조색 하나. 라임·형광 노랑·전기 파랑은 이미 너무 흔하니, 고른다면 이유가 있어야 한다 (주황, 신호 빨강, 시안, 호박색, 흰색 하나만 쓰기도 된다)

## 질감
- 1px 선, 눈금, 측정 표시
- 빛 번짐은 기본으로 넣지 않는다. 넣는다면 히어로에 하나, 내용과 관련 있을 때만

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 필요하면 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 12열, 넓은 바깥 여백. 글은 왼쪽 7열 안에서 */
  --max: 1360px; --margin: clamp(20px, 5vw, 72px); --gutter: 24px;
  /* 글자 크기: 1.333배 단계. 제목과 본문은 6배 이상 차이 */
  --fs-xs: 12px; --fs-sm: 14px; --fs-base: 16px; --fs-md: 21px; --fs-lg: 28px; --fs-xl: 38px;
  --fs-2xl: clamp(40px, 5vw, 64px); --fs-hero: clamp(52px, 8.4vw, 132px); --fs-figure: clamp(96px, 16vw, 240px);
  --lh-hero: 0.94; --lh-head: 1.08; --lh-body: 1.6; --measure: 34em;
  --track-hero: -0.035em; --track-head: -0.02em; --track-num: -0.01em;
  /* 여백: 8px 단위. 섹션 사이는 넉넉하게, 묶음 안은 좁게 */
  --s-1: 8px; --s-2: 16px; --s-3: 24px; --s-4: 40px; --s-5: 64px; --s-6: 104px; --section: clamp(112px, 15vw, 224px);
  /* 선과 모서리: 정밀하게. 둥글기는 작게, 선은 1px */
  --hairline: 1px solid color-mix(in srgb, var(--text) 14%, transparent); --radius: 3px;
  /* 명도 위계: --text 100 · --muted(팔레트) 64 안팎 · --faint 42 */
  --faint: color-mix(in srgb, var(--text) 42%, var(--bg));
  /* 움직임: 빠르게 들어오고 길게 멈춘다 */
  --ease: cubic-bezier(0.16, 1, 0.3, 1); --dur-1: 160ms; --dur-2: 360ms; --dur-3: 720ms;
}
```
`--faint`는 장식용 숫자와 눈금에만 쓴다. 읽어야 하는 글자에는 `--muted` 이상 (대비 4.5:1).

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example dark-tech` (구현할 때 한 번)

## 어울리는 모션
- 실제 값이 바뀌는 움직임: 숫자 올라감, 로그가 한 줄씩 쌓임, 그래프가 그려짐
- 커서를 따라오는 반응은 하나만
- 셰이더 배경은 히어로에만
- 강도: 중간

## 하지 말 것
- 위 "뻔한 버전"의 조합
- 네온을 여러 색으로, 빛 번짐을 섹션마다
- 대비가 낮아 읽기 힘든 회색 글자 (본문은 대비 4.5:1 이상)
