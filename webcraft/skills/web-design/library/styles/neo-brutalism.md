# neo-brutalism

두꺼운 검은 테두리, 어긋난 그림자, 쨍한 색. 거칠지만 의도된 느낌.

**어울리는 곳:** 크리에이티브 스튜디오, 이벤트, 커뮤니티, Z세대 대상 서비스, 사이드 프로젝트

## 뻔한 버전 (이렇게 나오면 실패)
- 미색 바탕 + 노랑·분홍·하늘 칸 + 4px 검은 그림자 카드가 똑같은 크기로 나열
- Space Grotesk 제목 + 기울인 스티커 몇 개를 장식으로만 붙임

## 레이아웃
- 블록이 분명하게 나뉜다. 정렬은 맞추되 일부 요소를 살짝 기울이거나 겹친다
- 큰 글자 덩어리와 스티커 같은 작은 요소
- 여백은 넉넉하지 않아도 된다. 꽉 찬 느낌이 어울린다

## 타이포
- 굵고 개성 있는 산세리프나 디스플레이 (Archivo Black, 검은고딕, 후보 목록의 Fontshare 디스플레이). Space Grotesk는 너무 흔하다
- 제목을 아주 크게, 대문자도 좋다
- 본문은 읽기 쉬운 산세리프

## 색
- 따뜻한 미색 배경에 원색 계열 2~3개 (노랑, 분홍, 파랑, 초록 중에서)
- 테두리와 그림자는 순수 검정

## 질감
- 2~4px 검은 테두리, 블러 없는 어긋난 그림자 (4px 4px 0 #000)
- 모서리는 각지거나 아주 살짝만 둥글게

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  /* 그리드: 12열, 바깥 여백은 좁게. 꽉 찬 느낌 */
  --max: 1440px; --margin: clamp(14px, 3vw, 40px); --gutter: 16px;
  /* 테두리와 그림자: 한 가지 두께, 블러 없음 */
  --bw: 3px; --border: var(--bw) solid var(--ink); --shadow: 6px 6px 0 var(--ink); --shadow-press: 2px 2px 0 var(--ink); --radius: 6px;
  /* 글자 크기: 1.414배 단계. 제목은 화면 폭을 기준으로 아주 크게 */
  --fs-sm: 14px; --fs-base: 17px; --fs-md: 24px; --fs-lg: 34px; --fs-xl: 48px;
  --fs-hero: clamp(64px, 13vw, 220px); --lh-hero: 0.86; --lh-head: 1; --lh-body: 1.5; --track-hero: -0.04em;
  /* 여백: 덩어리 사이는 좁게, 덩어리 안은 넉넉하게 */
  --s-1: 8px; --s-2: 14px; --s-3: 22px; --s-4: 36px; --s-5: 56px; --section: clamp(56px, 8vw, 112px);
  /* 기울기: 스티커만, 한두 개 */
  --tilt: -4deg; --tilt-2: 3deg;
  /* 움직임: 빠르고 딱딱하게 */
  --ease: cubic-bezier(0.3, 1.4, 0.5, 1); --dur-1: 90ms; --dur-2: 220ms;
  --ink: #111; /* 테두리와 그림자는 순수 검정에 가깝게 */
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example neo-brutalism` (구현할 때 한 번)

## 어울리는 모션
- 버튼을 누르면 그림자 쪽으로 눌려 들어가는 효과
- 스티커가 툭 붙는 듯한 등장, 살짝 흔들리는 호버
- 강도: 중간~높음, 대신 빠르고 짧게

## 하지 말 것
- 블러 그림자, 그라데이션, 유리 효과
- 원색을 4개 이상
- 부드럽고 느린 이징 (스타일과 안 맞는다)
