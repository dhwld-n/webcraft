# victorian

19세기 인쇄소와 서재의 품격. 고대비 세리프, 장식 테두리와 괘선, 대칭 구도, 짙은 녹색·와인·남색에 금색, 동판화 같은 그림, 첫 글자 장식. 오래된 책을 펼친 듯 정중하고 화려하다. 장식은 많지만 **대칭과 괘선이 질서**를 잡는다.

**어울리는 곳:** 위스키·와인·차, 향수·비누, 서점·출판, 고급 이발소, 클래식 공연, 역사 박물관, 보석, 전통 있는 호텔

**참고:** Royal Beverage(옛 음료 상표의 품격), daisyUI luxury 테마 토큰(거의 검정 `oklch(14% .004 286)` + 금색 글자 `oklch(75.7% .123 77)`)

## 뻔한 버전 (이렇게 나오면 실패)
- 검정 바탕 + 금색 Playfair Display + 금박 텍스처 이미지 (흔한 "럭셔리" 템플릿)
- 장식 테두리 PNG를 화면 둘레에
- 필기체 제목 + 꽃 장식 클립아트

## 레이아웃
- **대칭.** 가운데 축을 기준으로 제목, 장식 괘선, 작은 글자가 위아래로 쌓인다 (옛 상표·포스터·책 표지)
- 이중 괘선 테두리(굵은 선 + 가는 선)로 영역을 감싼다
- 위계: 작은 대문자 → 큰 제목 → 장식 괘선 → 이탤릭 부제 → 작은 정보
- 본문 섹션은 책처럼: 첫 글자 장식, 두 단, 각주

## 타이포
- 고대비 세리프 (Playfair Display, Bodoni Moda, Gloock, Abril Fatface / 한글 조선일보명조, 을유1945, 송명, 나눔명조)
- 작은 대문자(`font-variant: small-caps`, 영문)와 넓은 자간 0.12em으로 라벨
- 이탤릭 부제, 숫자는 옛 숫자(`font-variant-numeric: oldstyle-nums`)
- 한 줄 장식에만 필기체 (Great Vibes, Pinyon Script)

## 색
- 짙은 바탕 하나: 숲 녹색 `#1f3b2d`, 와인 `#5a1a24`, 남색 `#1b2340`, 또는 종이 `#f1e8d6`
- 금색 `#c9a45c` (선, 장식, 첫 글자), 크림 `#efe4cc` (글자)
- 금색은 그라데이션 금박 대신 단색으로. 진짜 인쇄 금색처럼

## 질감
- 이중 괘선: `border: 3px double`
- 장식 괘선: 가운데 마름모나 꽃 하나 + 양쪽으로 가는 선 (SVG 또는 `::before/::after`)
- 동판화풍 그림 (선 해칭), 종이 그레인 아주 옅게
- 모서리 장식은 네 귀퉁이 작은 L자 선 정도로 절제

### 비슷한 스타일과 구별
- **에디토리얼:** 현대 잡지, 비대칭 그리드. 빅토리안은 대칭과 장식
- **레트로:** 20세기 후반 상업 인쇄, 둥근 세리프와 쨍한 색. 빅토리안은 19세기, 고대비 세리프와 짙은 색

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  --max: 1080px; --margin: clamp(18px, 5vw, 72px); --gap: clamp(14px, 2vw, 28px);
  --forest: #1f3b2d; --wine: #5a1a24; --gold: #c9a45c; --cream: #efe4cc;
  /* 괘선 */
  --rule-double: 3px double var(--gold); --rule-thin: 1px solid color-mix(in srgb, var(--gold) 70%, transparent); --frame-inset: 10px;
  /* 글자 */
  --fs-xs: 12px; --fs-sm: 14px; --fs-base: 18px; --fs-lg: clamp(22px, 2.4vw, 30px); --fs-hero: clamp(52px, 8vw, 124px);
  --fw-body: 400; --fw-head: 700; --lh-head: 0.98; --lh-body: 1.7; --ls-caps: 0.14em;
  /* 움직임: 정중하게 */
  --ease: cubic-bezier(0.33, 1, 0.68, 1); --dur-1: 300ms; --dur-2: 1000ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example victorian` (구현할 때 한 번)

## 어울리는 모션
- 장식 괘선이 가운데에서 양쪽으로 그려진다
- 첫 방문 때 이중 테두리가 그려지고 제목이 천천히 나타난다 (`smooth-loader` 변형)
- 링크 밑줄이 그려지는 호버 (`hover-play` B)
- 강도: 낮음. 화려한 건 장식이지 움직임이 아니다

## 하지 말 것
- 금박 텍스처 이미지, 금색 그라데이션 글자
- 장식 테두리 클립아트를 화면 둘레에
- 필기체 본문
- 비대칭 배치 (빅토리안의 질서는 대칭이다)
