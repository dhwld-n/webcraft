# handwritten

사람의 손이 보이는 화면. 펜으로 쓴 제목, 연필 밑줄과 동그라미, 화살표 낙서, 공책 줄, 여백의 메모. 완벽하지 않은 선이 따뜻함과 진심을 전한다. 손글씨는 **강조와 목소리**에만 쓰고, 읽을 글은 반듯한 글꼴로 둔다.

**어울리는 곳:** 개인 블로그·뉴스레터, 작은 가게, 교육·어린이, 상담·마음 건강, 선물·카드, 요리 레시피, 동아리·커뮤니티

**참고:** ilovecreatives(친구 같은 말투), daisyUI의 caramellatte(크림 + 커피, 테두리 2px, 노이즈 1)·valentine 테마 토큰

## 뻔한 버전 (이렇게 나오면 실패)
- 페이지 전체를 손글씨 글꼴로 (읽기 힘들고 유치하다)
- 손글씨 글꼴 하나만 바꿔 넣고 손그림 요소는 없다
- 공책 줄무늬 배경 이미지를 화면 전체에 진하게

## 레이아웃
- 평범하고 단정한 레이아웃 위에 손의 흔적을 **덧칠**한다: 제목 옆 화살표, 단어 밑줄, 가격에 동그라미, 여백의 메모
- 메모는 본문 칸 바깥 여백에 비스듬히 (-3~4°)
- 손그림 요소는 한 화면에 2~4개
- 사진은 폴라로이드나 마스킹 테이프로 붙인 듯

## 타이포
- 손글씨: 제목 한 줄, 메모, 강조 단어 (영문 Caveat, Kalam, Patrick Hand / 한글 메모먼트꾹꾹체, 온글잎 계열, 교보손글씨, 나눔손글씨 펜, Gaegu)
- 본문: 단정한 고딕이나 세리프 (Pretendard, 고운바탕, Literata)
- 손글씨는 본문보다 크게 (1.3~2배). 작은 손글씨는 안 읽힌다
- 손글씨 글꼴 두 개를 섞지 않는다

## 색
- 바탕: 종이 `#fbf8f1`, 크림 `#f6efe2`
- 잉크: 짙은 남색 `#23305c` 또는 갈색 `#3d2b1f` (순검정보다 펜 같다)
- 형광펜 하나: 노랑 `#fff27a`, 분홍 `#ffb3c7` (밑줄 뒤 반투명 띠)
- 빨간 펜 `#d6352c`는 동그라미·화살표에만

## 질감
- 손그림 선: SVG `path`를 직접 그리고 `stroke-linecap: round`, 굵기 2~3px. 살짝 떨리는 곡선
- 형광펜: 글자 뒤 기울어진 반투명 띠 (`background: linear-gradient(...)` 높이 40%, 아래쪽)
- 종이: 아주 옅은 그레인, 공책 줄은 연한 파랑 1px

### 비슷한 스타일과 구별
- **콜라주:** 오려 붙인 조각이 주인공. 손글씨는 쓰고 그린 선이 주인공
- **두들(낙서):** 화면 전체가 그림. 손글씨는 단정한 화면 위의 손 흔적

## 수치 토큰
값은 출발점이다. 구도 스케치의 기준 수치로 옮겨 적고, 비율을 지키며 조정한다. 색과 글꼴은 system-designer가 정한 것을 쓴다.

```css
:root {
  --max: 1120px; --margin: clamp(18px, 4vw, 56px); --gap: clamp(14px, 2vw, 28px);
  --paper: #fbf8f1; --ink: #23305c; --red-pen: #d6352c; --marker: rgb(255 242 122 / 0.85);
  /* 손그림 */
  --pen: 2.5px; --note-tilt: -3deg;
  --highlight: linear-gradient(100deg, transparent 2%, var(--marker) 4% 96%, transparent 98%) 0 85% / 100% 42% no-repeat;
  /* 글자: 손글씨는 크게 */
  --fs-sm: 15px; --fs-base: 17px; --fs-lg: 24px; --fs-hand: clamp(26px, 3.2vw, 40px); --fs-hero: clamp(48px, 7.5vw, 110px);
  --fw-body: 400; --lh-head: 1.05; --lh-body: 1.7;
  /* 움직임: 그려진다 */
  --ease: cubic-bezier(0.65, 0, 0.35, 1); --draw: 900ms;
}
```

**모범 섹션 코드:** `node SKILL_DIR/scripts/lib.mjs example handwritten` (구현할 때 한 번)

## 어울리는 모션
- 밑줄, 동그라미, 화살표가 손으로 그리듯 그려진다 (`signature-draw`)
- 형광펜이 왼쪽에서 칠해진다 (`word-highlight`)
- 메모가 살짝 흔들리며 붙는다
- 강도: 낮음~중간

## 하지 말 것
- 본문, 버튼, 메뉴를 손글씨로
- 손글씨 글꼴 두 개 이상
- 완벽한 직선과 원 (도형 도구로 그린 선은 손글씨 세계를 깬다)
- 손그림 요소를 한 화면에 5개 이상
