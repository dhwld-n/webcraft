# Beautiful UI

- url: https://www.beautifului.dev
- styles: dark-tech, swiss
- industry: UI 컴포넌트 라이브러리 (AI 에이전트 인터페이스 전용)
- mood: 조용함, 정돈, 도구다움, 섬세함
- analyzed_at: 2026-11-01
- 라이선스: MIT (푸터에 "MIT License" 표기)
- 비고: 약 800px 너비 화면에서 확인함. 컴포넌트 라이브러리라 "레시피 후보" 항목을 덧붙임

## 첫인상
짙은 회색 화면 위쪽에 손글씨 같은 파란 선 로고와 작은 제목 하나. 그 아래로 번호가 붙은 컴포넌트가 하나씩 큰 칸 안에서 실제로 움직인다. 마케팅 문구 없이 작업물이 곧 소개다.

## 왜 좋은가
- **AI 인터페이스에만 집중한다.** 로딩, 생각 중, 스트리밍 답변, 승인 카드, 도구 칩, 작업 행, 채팅, 프롬프트 입력창처럼 AI 제품에 필요한 부품만 모았다. 범위가 좁아서 품질이 높다
- **번호 + 이름 + 한 줄 설명.** "01 Loading State — 픽셀 격자 로더, 반짝임, 경과 시간". 목록이 그대로 목차이자 설명서다
- **같은 데이터로 모든 예시를 이어 쓴다.** 아이스크림 가게 데이터(맛 분석, 공급업체, 피스타치오 매출)가 모든 컴포넌트에 쓰여서 하나의 제품을 둘러보는 느낌
- **제목이 작다.** 21px 정도. 큰 제목으로 소리치지 않고 컴포넌트에 무대를 내준다
- 칸 아래 작은 알약 탭(Steps, Reasoning, Search, Coding / Capsules, List)으로 같은 부품의 변형을 바로 바꿔 볼 수 있다

## 레이아웃
- 위: 왼쪽 손글씨 로고, 오른쪽 밝기 전환 알약
- 소개: 작은 제목, "Built by Turbo ←" 손그림 화살표, 짧은 설명, 작은 버튼
- 본문: 세로로 이어지는 큰 칸. 칸 위에 번호, 이름, 설명 한 줄. 칸 안 가운데에 실제 동작하는 컴포넌트, 아래 변형 탭

## 타이포
- Inter 하나. 제목 21px 굵기 600, 설명 11.5px 회색
- 경과 시간(4.1s) 같은 수치는 모노스페이스

## 색
- 배경: 짙은 회청색 (oklch 0.226)
- 칸: 배경보다 살짝 밝은 회색, 얇은 테두리
- 글자: 거의 흰색, 보조 회색
- 강조: 완료 상태 초록, 로고 파랑. 매우 절제
- 색 표기를 oklch로 관리

## 질감
- 둥근 칸, 얇은 테두리, 그림자 없음
- 손으로 그린 선 로고와 화살표 (유일한 손맛)

## 모션
- 픽셀 격자 로더에 반짝임 + 경과 시간
- "4초 동안 생각함" 펼침 목록, 단계별 체크
- 글자가 흘러나오는 스트리밍 텍스트
- 작업 행이 실행 중 → 완료로 바뀌는 상태 전환
- 캔버스 2개 (로더 등)

## 레시피 후보
MIT라 원리를 참고해 다시 구현해도 된다. 레시피 형식으로 새로 쓴다.
- **픽셀 격자 로더 + 경과 시간**: AI 응답 대기 화면
- **생각 중 펼침 목록**: 단계별 체크가 하나씩 켜짐
- **스트리밍 텍스트**: 글자 단위로 흘러나오는 답변 + 끝에 깜빡이는 커서
- **작업 상태 행**: 대기 → 실행 중(스피너 숫자) → 완료(초록 배지) 전환
- **도구 칩, 승인 카드, 프롬프트 바**: AI 제품 랜딩의 데모 영역에 쓰기 좋다

## 가져올 수 있는 것
- AI 제품 랜딩이라면 기능 설명 대신 이런 부품들이 실제로 움직이는 데모 영역
- 컴포넌트 쇼케이스: 번호 + 이름 + 한 줄 설명 + 변형 탭
- 모든 예시를 하나의 가상 회사 데이터로 통일
- 작은 제목, 큰 작업물

## 주의할 것
- React 전제. 순수 HTML 결과물이면 동작 원리만 가져온다
- 아주 절제된 회색 화면이라 그대로 따라 하면 밋밋해질 수 있다. 손그림 로고 같은 개성 하나가 필요하다
