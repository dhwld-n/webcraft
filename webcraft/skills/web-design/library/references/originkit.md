# Originkit

- url: https://www.originkit.dev
- styles: dark-tech, claymorphism, liquid-glass
- industry: 애니메이션 컴포넌트 라이브러리 (WebGL, Framer)
- mood: 촉감, 실험적, 화려함, 쇼케이스
- analyzed_at: 2026-11-01
- 라이선스: 확인 못 함. 제목에 "Free"라고 적혀 있지만, 사이트 본문과 컴포넌트 상세 페이지에서 라이선스 문구를 찾지 못했다. 코드는 "Get this Component"(로그인 필요로 보임) 뒤에 있다
- 비고: 노션의 "애니메이션 레시피 라이브러리" 출처. 약 800px 너비 화면에서 확인함

## 첫인상
검은 바탕에 컴포넌트 카드가 2열 격자로 끝없이 이어진다. 카드마다 빛나는 꽃밭 지형, 털 달린 앱 아이콘, 유리 키보드, 소용돌이, 구름 하늘이 실제로 움직인다. 컴포넌트가 805개다.

## 왜 좋은가
- **질감 자체가 컴포넌트다.** 버튼 하나도 벨벳, 털, 유리, 독액 같은 재질로 만든다. 평면 UI에 촉감을 입히는 아이디어 창고
- **카드 격자 쇼케이스.** 카드마다 미리보기가 실제로 돌아가고, 아래에 이름과 조회수. 고르는 재미가 있다
- **이름을 시적으로 짓는다.** Glimmer Vale, Velour Bolster, Accretion Disc, Still Sunset Meadow. 이름만으로 느낌이 전해진다
- 상세 페이지에 기능 설명을 기술적으로 적는다 (예: "120Hz 고정 주기로 변위 격자를 시뮬레이션해 솜이 출렁이듯")

## 레이아웃
- 위: 둥근 떠 있는 헤더 (로고, 로그인, 메뉴), 아래 세그먼트 탭 (Components, Sections, Templates)
- 광고 띠 한 줄, "Discover 805 Components" + 보기 전환
- 2열 카드 격자, 카드 = 큰 미리보기 + 이름 + 조회수 + "New" 배지
- 상세: 뒤로 가기, 이름, 분류 배지, 큰 미리보기 칸, "Get this Component" 버튼, 설명과 주요 특징

## 타이포
- Inter, 작게 (14~18px). 컴포넌트가 주인공이라 글자는 조용하다

## 색
- 배경: 거의 검정 `rgb(15,15,16)`
- 카드: 어두운 회색, 얇은 테두리
- 로고 주황, 그 외 색은 전부 컴포넌트에서

## 질감
- 둥근 카드와 헤더, 반투명 떠 있는 헤더

## 모션
- 카드마다 WebGL, 영상 미리보기가 상시 재생
- 들어가자마자 템플릿 광고 팝업이 뜬다 (닫기 버튼으로 닫음)

## 레시피 후보
라이선스가 확인되지 않았으므로 코드를 가져오지 않는다. 아래는 동작 원리만 참고해 직접 구현할 아이디어다.
- **Velour Bolster** (버튼): 평소엔 납작하다가 커서 쪽으로 쿠션처럼 부풀고, 누르면 움푹 들어갔다 튕겨 나오는 벨벳 버튼. 글자와 결도 천과 함께 움직인다. **클레이모피즘 레시피의 핵심 아이디어**. 가볍게는 CSS `transform` + 스프링(magnetic-button 레시피 응용) + 안쪽 그림자로 흉내 낼 수 있다
- **Plush Tile** (Framer용): 털로 덮인 앱 아이콘 타일 (상세 미리보기가 로딩되지 않아 목록 썸네일로만 확인)
- **Single Glass Keyboard**, **Glass Icon**: 유리 재질 아이콘과 키 → 리퀴드 글래스 레시피 후보
- **Glimmer Vale**: 빛나는 점들이 흩뿌려진 물결 지형 → 히어로 배경
- **Cloud Sky**, **Still Sunset Meadow**: 하늘, 노을 풍경 배경
- **Tornado**, **Accretion Disc**, **Wire Terrain**, **Globe**: 3D 셰이더 오브젝트
- **Cursor Ring Field**, **Spider Button**, **Venom Button**: 커서 반응 인터랙션
- **Coverflow Gallery**, **Spiral Images**: 이미지 갤러리 배치

## 가져올 수 있는 것
- 버튼, 아이콘 같은 작은 요소에 재질(벨벳, 털, 유리)을 입혀 촉감 만들기
- 클레이모피즘: 부풀기 + 눌림 + 튕김의 3단계 반응
- 컴포넌트 쇼케이스: 실제로 움직이는 미리보기 카드 격자 + 시적인 이름

## 주의할 것
- **라이선스를 먼저 확인한다.** 레시피로 만들 땐 코드를 보지 않고 원리만으로 새로 짠다
- 대부분 WebGL이라 무겁다. 한 페이지에 하나만
- 카드 수십 개가 동시에 재생되어 이 사이트 자체도 무겁다
