## 첫인상
짙은 회색 바탕 가운데에 흰 큰 문장 두 줄, 그 뒤로 흐릿한 상품 썸네일이 벽처럼 깔려 있다. 아래는 상품 카드 4열. 디자이너용 가게답게 매끈하지만, 어디서 본 듯하다.

## 왜 좋은가 (진열 방식에서 배울 것)
- **썸네일 벽 위의 문장.** 상품 미리보기를 어둡게 흐려 배경에 촘촘히 깔고 가운데 문장만 밝게 둔다. "많다"를 숫자 대신 화면으로 보여 준다
- **기울여 늘어놓은 여러 화면.** 미리보기 이미지는 앱 화면 여러 장을 같은 각도로 기울여 줄지어 놓는 방식이 많다. 화면 하나보다 "규모"가 느껴진다
- **어두운 바탕 단계.** `#121212` 바탕, 카드 `#202020`, 그 위 `#262626`. 검정을 세 단계로 나눠 깊이를 만든다

## 상품 이름으로 본 요즘 흔한 것 (2026-11 홈 화면)
- 거의 모든 앱 키트 이름에 "AI"가 붙는다 (AI 코치, AI 챗봇, AI 음성 비서, AI SaaS 대시보드, AI 여행 플래너)
- "Dark & Light" 두 벌 제공
- 등각(아이소메트릭) 3D 빈 화면 일러스트 묶음
- 휴대폰 3D 모델 목업
- 핀테크·습관·웰빙 앱이 많다

## 레이아웃
- 첫 화면: 가운데 정렬 큰 문장(왼쪽 24% 위 22%, 폭 53%), 아래 탭(추천, 인기, 최신), 카드 4열
- 카드: 썸네일 + 이름 + 가격 + 만든 사람, 둥글기 16px, 간격 24px
- 아래로 카테고리 카드 3열(간격 48px)

## 타이포
- CircularXX 한 가지, 굵기 450 (400과 500 사이 가변 굵기)
- 제목 48px, 본문 15px (3.2배). 자간 -0.02em으로 본문까지 살짝 좁힌다

## 색
- 바탕 `#121212`, 면 `#202020` `#262626` `#181818`, 글자 `#ffffff`, 보조 글자 `#adb7be`
- 강조 파랑 `#2d68ff`, `#2997ff`

## 질감
- 둥글기 12~16px 카드, 알약 버튼
- 그림자 23개, 흐림 없음

## 모션
- 가장 인상적인 것: 카드 호버 때 위로 뜨고(transform) 밝아진다. 200ms ease, 길게는 800ms
- `cubic-bezier(0.215, 0.61, 0.355, 1)` (easeOutCubic) 300~400ms
- CSS 애니메이션 48개, 캔버스 9개 (썸네일 미리보기)

## 가져올 수 있는 것
- 작품, 상품이 많은 사이트: 미리보기를 어둡게 흐려 벽처럼 깔고 문장만 밝게
- 어두운 바탕을 `#121212` / `#202020` / `#262626` 세 단계로
- 가변 굵기 450처럼 400과 500 사이 굵기로 본문을 조금 단단하게
- 앱 화면 여러 장을 같은 각도로 줄지어 기울이기 (규모 표현)

## 주의할 것 (이게 핵심)
- 여기 상품들의 공통점이 곧 "AI가 만든 웹사이트"의 공통점이다: 어두운 바탕 + 파랑 강조 + 둥근 카드 4열 + 가운데 정렬 큰 문장 + 3D 휴대폰 목업 + 등각 3D 일러스트. 이 조합이 나오면 다시 생각한다
- UI 키트를 그대로 가져다 쓴 듯한 화면은 피한다. 진열 방식만 원리로 가져온다
