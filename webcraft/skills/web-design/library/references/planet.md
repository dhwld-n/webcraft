## 첫인상
별이 흩뿌려진 검은 우주 배경에 "홈페이지, 꼭 필요한가요?"라는 질문. 이어서 노트북 화면 속 우주비행사와 "PLANET" 글자. 이후로는 흰 바탕에 짧은 문장들이 차근차근 설득한다.

## 왜 좋은가
- **질문으로 시작한다.** 고객이 속으로 하는 의심("홈페이지가 꼭 필요해?")을 제목으로 꺼내고 바로 "네! 필요합니다"라고 답한다. 한국 소상공인 대상 카피의 좋은 예
- **우주 도입 → 흰 정보 섹션의 전환.** 첫 화면만 이름(Planet)에 맞춘 우주 분위기로 시선을 끌고, 본론은 읽기 쉬운 흰 바탕으로 바꾼다. 감성과 정보의 역할을 나눴다
- **고객의 행동 순서를 단계 카드로.** "먼저 검색 → 비교 → 확인" 3단계를 체크 표시와 세로 선으로 이은 카드로 보여주고, 스크롤하면 단계가 차례로 체크된다
- **한 단어를 검정 블록으로 강조.** "문의 전 신뢰"처럼 핵심 단어에 검정 배경 + 흰 글자를 씌워 형광펜보다 단단한 강조
- **SNS와 비교해 필요를 설명.** 인스타그램, 블로그, 플레이스 카드마다 "이건 좋지만, 이건 부족하다"를 두 줄로. 고객이 이미 쓰는 도구에서 출발한다

## 레이아웃
- 위: 왼쪽 이탤릭 굵은 로고, 오른쪽 둥근 버튼 "PLANET 보러가기" (도입부에선 회색, 흰 섹션에선 검정)
- 도입: 가운데 정렬 질문 제목 + 굵은 답 + 두 줄 설명 + 노트북 목업 + 흰 알약 버튼
- 본문: 가운데 정렬 큰 제목 2줄, 아래 세로로 쌓인 카드들
- 카드: 옅은 파랑 배경, 파란 테두리, 왼쪽 위 작은 영문 라벨, 굵은 한글 제목, 회색 설명, 오른쪽 작은 일러스트 아이콘

## 타이포
- Pretendard 하나. 제목 65px 굵기 700, 자간 좁게
- 강조 문장은 파랑 (예: "홈페이지는 정리합니다.")
- 본문 18px, 회색

## 색
- 도입: 검정 + 흰 별 점
- 본문: 흰 바탕, 검정 글자, 강조 파랑 (대략 `#3b6cf5`)
- 카드: 아주 옅은 파랑 바탕 + 파란 테두리, 또는 옅은 회색
- 버튼: 검정 알약 (본문), 흰 알약 (도입)

## 질감
- 둥근 카드 (12~16px), 얇은 테두리
- 별이 뜬 우주 배경 (캔버스)
- 그림자 거의 없음

## 모션
- 별 배경 (캔버스 1개)
- GSAP + Lenis 관성 스크롤
- 스크롤하면 노트북 목업이 올라오고, 단계 카드가 순서대로 체크된다

## 가져올 수 있는 것
- 한국어 서비스 랜딩: 고객의 의심을 질문형 제목으로 꺼내고 바로 답하기
- 브랜드 이름에 맞춘 감성 도입은 첫 화면만, 본론은 흰 바탕 정보형으로
- 고객 행동 단계를 체크 표시 세로 타임라인 카드로
- 핵심 단어 하나에 검정 블록 강조
- 고객이 이미 쓰는 도구와 비교해서 필요성 설명

## 주의할 것
- 흰 바탕 + 파란 카드 구조는 한국 SaaS 랜딩에서 매우 흔하다. 도입부 같은 차별화 장면이 꼭 하나 필요하다
- 페이지가 아주 길다(높이 2만 픽셀 이상). 중간중간 행동 버튼을 반복한다
- 우주비행사 이미지와 PLANET 로고는 고유하다
