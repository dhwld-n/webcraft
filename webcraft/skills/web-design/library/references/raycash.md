## 첫인상
암호화폐 앱인데 첫 화면이 풀밭에 앉아 휴대폰을 보는 사람의 햇살 사진이다. 왼쪽 위에 화면 절반을 차지하는 아주 굵고 촘촘한 흰 제목 세 줄. "코인"이 아니라 "평범한 하루"를 판다.

## 왜 좋은가
- **업계 관습을 뒤집은 사진.** 핀테크·코인 사이트의 검정 바탕, 네온, 3D 동전 대신 야외 자연광 인물 사진. 차별점이 사진 한 장으로 끝난다
- **아주 굵고 촘촘한 제목.** 94px(본문의 6.7배), 굵기 700, 행간 0.90, 자간 -0.04em. 글자가 서로 붙을 만큼 좁혀서 덩어리로 읽힌다. 사진 위에서도 흔들리지 않는다
- **알약 모양으로 오린 사진.** 아래 섹션은 미색 바탕 위에 가로로 긴 알약(스타디움) 모양으로 사진을 오리고, 가운데에 앱 화면 휴대폰을 세운다. 사각형 사진보다 부드럽고 브랜드 모양이 된다
- **모노 대문자를 작은 곳에만.** 메뉴와 작은 라벨만 모노스페이스 대문자. 제목의 굵은 그로테스크와 대비돼 "기술 회사"라는 신호를 조용히 준다
- **따뜻한 미색과 커피색.** 바탕 `#fefdf0`, 글자 `#28211b`. 순백과 순검정 대신 조금씩 따뜻하게 틀어서 사진의 햇살과 맞춘다

## 레이아웃
- 첫 화면: 전체 화면 사진, 위 가운데 로고, 왼쪽 위 모노 메뉴, 오른쪽 위 노란 알약 버튼, 제목은 왼쪽 2% 위 14%에서 폭 53%
- 가입 폼은 오른쪽 아래 구석에 흰 입력칸 + 짙은 갈색 버튼으로 작게
- 이어지는 기능 섹션: 미색 바탕, 알약 모양 사진 + 가운데 휴대폰 + 양옆에 제목 한 줄과 설명 두 줄
- 화면별 배경: 미색 ×9 → 짙은 갈색 → 미색 ×2 → 연한 베이지 → 짙은 갈색
