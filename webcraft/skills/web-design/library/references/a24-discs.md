## 첫인상
거의 흰 빈 화면에 CD 한 장이 비스듬히 떠서 천천히 돈다. 디스크 표면이 영화 포스터라서 메뉴판이 아니라 진열장 앞에 선 느낌이다. 글자는 화면 가장자리에 아주 작게만 있다.

## 왜 좋은가
- **물건 하나를 은유로 고정했다.** 영화 목록이 "카드"가 아니라 "디스크"라서 3D로 만들 이유가 분명하다. 3D가 장식이 아니라 내용의 그릇이다
- 3D 오브젝트는 원기둥 하나 수준으로 단순하다. 풍부함은 **실제 이미지 텍스처**와 조명의 반사에서 온다
- 빈 배경 + 작은 글자 + 큰 물체. 대비가 극단적이라 물체에 시선이 꽂힌다
- 스크롤하면 디스크들이 비스듬한 곡선 위로 줄지어 흘러간다. 스크롤이 곧 탐색이다
- 디스크를 누르면 같은 디스크가 상세 페이지로 이어지며, 세리프 큰 제목과 표 같은 정보 줄이 나온다. 목록과 상세가 끊기지 않는다

## 레이아웃
- 첫 화면: 가운데 물체 하나, 네 모서리에 작은 글자 (로고, 메뉴, 쪽수)
- 목록: 화면을 가로지르는 비스듬한 줄. 현재 항목 정보는 왼쪽 위 작은 표, 평점은 아래 작은 인용 두 개
- 상세: 가운데 큰 세리프 제목, 아래 가는 선으로 나뉜 정보 줄 (감독, 연도, 장르, 상영 시간)

## 타이포
- 제목: 대비 큰 디스플레이 세리프 (Pangram Pangram 계열 유료 폰트로 추정)
- 정보 줄: 아주 작은 그로테스크 대문자 라벨 + 값
- 인용: 작은 세리프 대문자에 별점

## 색
- 배경 따뜻한 밝은 회색 (#EEEDEB 근처), 글자 검정
- 색은 전부 포스터 이미지에서 온다. UI 자체에는 강조색이 없다

## 질감
- 디스크 가장자리의 투명 플라스틱, 가운데 구멍의 은색 링, 표면의 반사광
- 그림자 없이 공중에 떠 있다

## 모션
- 가장 인상적인 것: 스크롤에 따라 디스크 줄이 곡선을 따라 미끄러지며 각 디스크가 제자리에서 기울기를 바꾼다. 관성이 있어 멈출 때 부드럽다
- 첫 화면 디스크는 느리게 자전한다
- 페이지가 바뀔 때 화면이 새로 뜨지 않고 이어진다 (부드러운 스크롤 + 페이지 전환 라이브러리)

## 가져올 수 있는 것
- 콘텐츠를 상징하는 물건 하나로 3D를 정당화한다 (책, 레코드, 티켓, 카세트, 필름 통, 우표, 명함)
- 단순한 도형 + 실제 이미지 텍스처 + 반사 = 적은 코드로 큰 물성
- 빈 배경에 물체 하나, 글자는 가장자리에 작게
- 스크롤을 탐색으로: 목록 전체가 하나의 곡선 위를 흐른다
- 목록에서 상세로 같은 물체가 이어지는 전환

## 주의할 것
- CD + 영화 포스터 조합, 비스듬한 디스크 줄 배치는 이 사이트의 얼굴이다. 같은 물건, 같은 배치를 쓰면 베낀 티가 난다
- 폰트는 유료(Pangram Pangram)라 같은 것을 쓰지 않는다
