## 첫인상
따뜻한 미색 바탕 위에 하늘색 그라데이션 카드가 떠 있고, 그 안에 찢은 종이를 오려 붙인 듯한 풍경 콜라주. 생산성 앱인데 문구점에 들어온 것 같은 손맛이 있다.

## 왜 좋은가
- **디지털 도구를 종이 질감으로 표현했다.** 찢긴 종이 가장자리, 거친 그레인이 들어간 색 면이 "나만의 공간"이라는 메시지와 맞는다
- **한글 세리프 제목이 품위를 준다.** Untitled Serif에 함렛(Hahmlet)을 한글 대체로 지정해, 한국어 페이지에서도 영어판과 같은 결이 유지된다. 한국어 사이트를 만들 때 특히 참고할 점
- **히어로를 페이지 전체가 아니라 둥근 카드 안에 담았다.** 바깥 미색 여백이 액자 역할을 해서 히어로가 작품처럼 보인다
- **사용자 사례를 인물 사진 + 질감 있는 색 배경 카드로.** 사진마다 다른 파스텔 배경을 깔아 가로 목록이 경쾌하다
- 큰 색 판(연보라) 위에 실제 앱 화면 조각을 겹쳐 놓아 기능 설명이 그림처럼 읽힌다

## 레이아웃
- 위쪽에 떠 있는 알약 모양 내비게이션 (반투명 흰색, 가운데 정렬)
- 히어로: 둥근 카드 안에 가운데 정렬 큰 제목 2줄 + 작은 검정 알약 버튼, 아래 콜라주
- 이후: 아이콘 5개 가로 한 줄(문서, 작업, 캘린더 등), 사례 카드 가로 스크롤
- 기능 섹션: 페이지 폭보다 약간 좁은 큰 둥근 색 판, 왼쪽에 앱 화면, 오른쪽에 제목·설명·버튼·기능 목록

## 타이포
- 제목: Untitled Serif (한글은 함렛), 66px, 굵기 400, 자간 좁게(-2px)
- 본문: Untitled Sans (한글은 IBM Plex Sans KR), 16px, 굵기 500
- 제목은 가늘고 크게, 본문은 작고 단단하게

## 색
- 바탕: 따뜻한 미색 `rgb(252,249,247)`
- 글자: 거의 검정 `rgb(3,3,2)`
- 히어로: 하늘색 그라데이션, 콜라주는 파랑·회색·흰색
- 기능 판: 연보라, 카드: 복숭아색
- 버튼: 검정 알약

## 질감
- 찢긴 종이 가장자리, 그레인 노이즈가 섞인 색 면
- 큰 모서리 둥글기 (판 단위로 24px 이상)
- 그림자는 아주 옅게

## 모션
- 정적인 편. 사례 카드 가로 스크롤, 내비게이션 고정
- 콜라주와 질감이 볼거리라 모션을 아꼈다

## 가져올 수 있는 것
- 한국어 사이트에서 세리프 제목을 쓸 때 함렛, 마루부리, Noto Serif KR 같은 한글 세리프를 대체 폰트로 지정
- 히어로를 둥근 카드 안에 넣어 바깥 여백을 액자로
- 그레인 노이즈 + 찢긴 가장자리로 손으로 만든 느낌 내기 (SVG 필터 `feTurbulence`)
- 큰 색 판 위에 제품 화면 조각을 겹쳐 놓는 기능 설명

## 주의할 것
- 콜라주 그림은 이 브랜드의 고유 일러스트다. 질감 기법만 가져오고 그림 자체는 새로 만든다
- 그레인을 모든 면에 깔면 지저분해진다. 히어로와 강조 판에만
