## 첫인상
분홍 점무늬 바탕 위에 옛날 매킨토시 창 하나가 떠 있고, 그 안에서 90년대 비디오테이프 같은 화질의 요트 영상이 재생된다. 아래에는 픽셀 아이콘이 늘어선 독. 웹사이트가 아니라 1997년의 컴퓨터 바탕화면이다.

## 왜 좋은가
- **사이트 전체가 하나의 은유다.** 페이지를 스크롤하는 대신 "운영체제"를 쓴다. 메뉴는 독의 아이콘이고, 내용은 창으로 열린다. 은유를 끝까지 밀어붙여 몰입이 생긴다
- **날짜까지 연출.** 오른쪽 위 시계가 오늘 날짜를 1997년으로 보여준다. 작은 디테일 하나로 세계관이 완성된다
- **픽셀 비트맵 폰트를 아주 작게.** 10~16px의 비트맵 폰트(Ishmeria, Everyday)를 써서 진짜 옛 화면처럼 보인다
- **부드러운 파스텔 + 거친 영상.** 분홍 바탕과 미색 창은 깔끔한데, 영상은 일부러 저화질 VHS 질감. 대비가 향수를 키운다

## 레이아웃
- 화면 높이 하나로 끝난다. 스크롤 없음
- 위: 왼쪽 메뉴바 (회원 가입, 로그인), 오른쪽 날짜와 시각
- 가운데: 미디어 플레이어 창 (제목 줄, 영상, 곡 정보, 재생 버튼)
- 아래: 픽셀 아이콘 독 (플레이어, 뉴스, 믹스테이프, 회원, 이벤트, 인스타그램, 방명록, 앱)

## 타이포
- 제목과 본문 모두 비트맵 픽셀 폰트, 10~16px
- 자간을 좁게(-1px), 대문자 메뉴
- 큰 글자가 없다. 작은 글자들이 오히려 진짜 같다

## 색
- 바탕: 분홍 `rgb(246,213,213)` + 작은 점무늬
- 창: 미색, 검은 1px 테두리
- 재생 버튼: 하늘색, 강조 버튼에 빨간 하트
- 영상의 바랜 색감

## 질감
- 1px 검은 테두리 창, 제목 줄에 가로 줄무늬
- 점무늬 바탕 (디더링 느낌)
- VHS 노이즈, 저해상도 영상

## 모션
- 영상 재생이 핵심. UI 자체는 창 열기, 닫기 같은 운영체제식 동작
- 화려한 전환 없음. 옛날 컴퓨터처럼 즉각적으로 뜬다

## 가져올 수 있는 것
- 사이트 전체를 하나의 물건(운영체제, 잡지, 카세트, 게임기)으로 은유하고 끝까지 지키기
- 날짜, 시계, 상태 표시 같은 작은 디테일로 세계관 만들기
- 레트로 스타일이면 비트맵 폰트를 작게, 1px 테두리, 점무늬 디더링
- 깔끔한 UI + 일부러 거친 미디어의 대비

## 주의할 것
- 옛 매킨토시 창 모양과 Poolsuite의 아이콘, 폰트는 고유하다. 시대 분위기만 가져오고 창 디자인은 새로 그린다
- 비트맵 폰트는 한글이 없다. 한국어 사이트라면 한글 픽셀 폰트(예: 둥근모꼴, Galmuri)를 짝으로
- 글자가 매우 작아 접근성이 약하다. 본문은 최소 14px 이상으로
- 은유가 강할수록 처음 온 사람이 길을 잃는다. 주요 행동 하나는 평범하게 보이게
