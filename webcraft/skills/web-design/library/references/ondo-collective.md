## 첫인상
짙은 숲색 화면에서 시작해, 초점이 흐린 초록 숲 영상 위로 가는 흰 선이 실처럼 흘러다닌다. 가운데 원형 로고, 아래 "We weave context." 브랜딩 스튜디오인데 명상 앱 같은 고요함이 있다.

## 왜 좋은가
- **이름과 메시지를 그래픽 하나로.** "맥락을 엮는다"는 말에 맞춰 손으로 그린 듯한 흰 실 선이 화면을 가로지르며 엮인다. 개념이 바로 눈에 보인다
- **초점 흐린 자연 영상이 배경.** 선명한 사진보다 감정이 먼저 오고, 위의 글자와 선이 잘 읽힌다
- **거친 흑백 그레인 장면으로 분위기 전환.** 초록 → 흑백 입자 → 짙은 녹색 → 복숭아색 미색으로 장마다 온도가 바뀐다
- **영문 대문자 세리프 + 일본어 본문.** 큰 영문 제목은 얇은 고대비 세리프, 본문은 일본어 산세리프. 동아시아 언어 사이트에서 영문을 장식 요소로 쓰는 좋은 예. 한국어 사이트에도 그대로 통한다
- 이미지를 화면 가득이 아니라 여백 안에 큰 액자처럼 넣어 갤러리 같은 호흡

## 레이아웃
- 위: 왼쪽 원형 로고, 오른쪽 작은 메뉴 (HOME, PROJECTS, VISUALS, CONTACT)
- 히어로: 가운데 로고와 실 선, 아래 가운데 작은 제목과 설명
- 소개: 왼쪽에 큰 영문 대문자 제목 + 일본어 소제목 + 본문, 오른쪽 절반은 사진 (2열 반반)
- 이후 여백 안에 큰 이미지 액자, 섹션 라벨은 작게 왼쪽 위
- 오른쪽 아래에 "Sections" 같은 작은 길잡이

## 타이포
- 제목: 자체 세리프(Ondo), 얇고 고대비, 영문 대문자, 자간 넓게
- 본문: Poppins 계열 + 일본어 고딕, 16px
- 히어로 제목 48px, 크지 않고 조용하다

## 색
- 짙은 숲색 `rgb(0,60,38)` (본문 글자와 배경 둘 다)
- 복숭아빛 미색 `rgb(243,229,222)` 배경
- 흰 선과 흰 글자
- 흑백 입자 장면

## 질감
- 강한 필름 그레인, 초점 흐림
- 손으로 그린 듯한 가는 곡선
- 테두리, 그림자 없음

## 모션
- **가장 인상적인 것: 흰 실 선이 화면 위를 천천히 흘러다니며 엮이는 효과** (캔버스로 그림)
- 배경 영상 (흐린 자연)
- 섹션마다 배경색이 바뀌는 전환
- 전체적으로 느리고 부드럽다

## 가져올 수 있는 것
- 브랜드 메시지를 선 하나의 움직임으로 표현하기 (SVG 경로 애니메이션이나 캔버스 곡선)
- 흐린 영상 배경 + 얇은 세리프 글자로 고요한 분위기
- 한국어 사이트에서 영문 대문자 세리프를 장식 제목으로, 한글은 본문으로
- 장마다 배경 온도(녹색 → 흑백 → 미색) 바꾸기

## 주의할 것
- 흐린 배경 위 흰 글자는 대비가 약해지기 쉽다. 글자 뒤에 어두운 막을 깐다
- 첫 화면이 몇 초간 단색만 보였다. 로딩이 길다
- 자체 폰트와 실 그래픽은 고유하다
