## 첫인상
밝은 회색 바탕의 큰 슬라이드에 작품 사진 하나, 아래로 사진 카드가 3열로 이어진다. 대기업 사이트지만 광고가 아니라 디자인 잡지처럼 보인다.

## 왜 좋은가
- **기업 사이트를 매거진으로 만들었다.** 제품 판매 대신 "이야기"가 단위. 카드마다 큰 사진, 영문 제목, 한글 부제, 날짜, 태그가 있어 기사 목록처럼 읽힌다
- **사진이 모든 걸 말하게 비워 둔다.** 회색과 흰 바탕, 검정 글자뿐. 색은 작품 사진에서만 나온다
- **영문 제목 + 한글 부제의 2단 구성.** "'26 Design Miami Seoul: Artworks" 아래 "2026 디자인 마이애미 서울 Part 2". 글로벌 브랜드와 국내 독자를 동시에 챙긴다
- **굵은 검정 알약 태그 구름.** 페이지 아래 "Discover by Tag"에서 CMF, Branding, UX/UI 같은 태그를 크고 굵은 검정 알약으로 늘어놓아, 차분한 페이지 끝에 힘을 준다
- 자체 서체(삼성 원, 삼성 샤프 산스)로 브랜드 목소리를 통일

## 레이아웃
- 위: 왼쪽 로고, 바로 옆 메뉴 5개, 오른쪽 아이콘 3개. 아주 얇은 헤더
- 히어로: 화면 폭 슬라이드, 회색 바탕에 작품 사진, 좌우 화살표, 아래 점 표시
- "Latest Stories": 3열 카드 그리드, 카드 높이가 서로 달라 지그재그로 어긋난다 (석조 배치)
- 카드: 사진 → 영문 제목 → 한글 부제 → 날짜 → 작은 태그 알약들
- 아래: 큰 검정 알약 태그 구름, 가로로 넘친다

## 타이포
- 영문: Samsung One / Samsung Sharp Sans, 한글: 삼성 전용 서체, 대체로 맑은 고딕
- 카드 제목 약 20px, 부제와 날짜는 작게
- 태그 알약 글자는 크고 굵게

## 색
- 바탕: 흰색, 히어로는 밝은 회색
- 글자: 검정
- 태그: 검정 알약에 흰 글자
- 그 외 색은 사진에만

## 질감
- 사진 카드 모서리 살짝 둥글게, 테두리 없음
- 그림자 없음

## 모션
- 히어로 슬라이드 (Swiper)
- 그 외 거의 없음. 사진과 여백으로 승부

## 가져올 수 있는 것
- 기업, 기관 사이트를 매거진 형식(이야기 카드)으로
- 영문 제목 + 한글 부제 2단 구성
- 높이가 다른 카드의 석조 배치로 단조로움 깨기
- 페이지 끝에 크고 굵은 태그 알약 구름으로 탐색 유도

## 주의할 것
- 사진 품질이 전부다. 사진이 평범하면 텅 빈 사이트가 된다
- 삼성 전용 서체는 쓸 수 없다. 비슷한 느낌은 Pretendard + 기하학적 영문 산세리프로
- 히어로 슬라이드 글자가 사진 위에서 잘 안 보였다 (회색 바탕에 연한 글자). 대비를 확인한다
