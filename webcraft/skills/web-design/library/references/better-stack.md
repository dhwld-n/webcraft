## 첫인상
남색이 도는 검정 배경, 왼쪽에 큰 제목과 이메일 입력창, 오른쪽에 비스듬히 기울어진 로그 화면. 전형적인 개발자 SaaS지만 군더더기가 없다.

## 왜 좋은가
- **가입까지 한 동작.** 히어로에 이메일 입력과 보라 버튼이 붙어 있어 읽자마자 시작할 수 있다
- **경쟁사 대비 숫자를 크게 보여준다.** "30배 저렴", 데이터 양과 가격 비교표를 큰 숫자로 배치해 설득을 말이 아닌 수치로 한다
- **제품 화면을 원근감 있게 기울였다.** 평면 스크린샷보다 공간감이 생기고, 옆에서 들여다보는 느낌
- 제품군이 많은데 섹션마다 "제목 + 가로 카드 넘기기" 같은 틀을 반복해 길어도 길을 잃지 않는다

## 레이아웃
- 히어로: 왼쪽 텍스트 열, 오른쪽에 기울어진 제품 화면, 아래 고객 로고 한 줄
- 중반: 가격 비교 블록 (큰 숫자 2개 + 비교 표)
- 이후: 제품별 섹션이 반복. 큰 제목 왼쪽, 오른쪽 위에 넘기기 버튼과 "더 보기" 링크, 아래 카드 가로 목록
- 섹션 사이 여백이 넉넉하다

## 타이포
- Helvetica Now Display (제목), Helvetica Now Text (본문)
- 제목 53px, 굵기 500. 글자색에 그라데이션을 입혀(배경 클립) 위아래로 은은하게 밝기가 바뀐다
- 본문 20px, 푸른 회색 `rgb(147,157,184)`

## 색
- 배경: 남색 검정 `rgb(11,12,20)`
- 본문: 푸른 회색, 제목: 흰색 계열 그라데이션
- 강조: 보라 (가입 버튼), 아주 아껴서
- 카드는 배경보다 한 단계 밝은 남색

## 질감
- 둥근 모서리 카드, 얇고 어두운 테두리
- 로고 줄은 회색 단색으로 통일

## 모션
- 히어로 제품 화면이 슬라이드처럼 바뀐다 (아래 점 표시)
- 카드 목록 가로 넘기기
- 카드 안 그래픽은 스크롤해 보일 때 나타나는 것으로 보인다 (빠르게 스크롤하면 비어 보였다)
- 전체적으로 절제. 큰 WebGL이나 관성 스크롤 없음

## 가져올 수 있는 것
- 히어로에 바로 가입 가능한 입력창 붙이기
- 가격 경쟁력을 큰 숫자 비교로 보여주기
- 제품 화면에 원근 기울기를 줘서 평범한 스크린샷을 입체적으로
- 긴 페이지는 섹션 틀을 하나 정해 반복

## 주의할 것
- 그라데이션 글자는 대비가 낮아지기 쉽다. 가장 어두운 부분도 4.5:1 이상인지 확인
- 이 구조는 SaaS에서 매우 흔하다. 그대로 따라 하면 평범해 보인다. 차별화 요소 하나가 더 필요하다
