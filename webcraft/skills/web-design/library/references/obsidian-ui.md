## 첫인상
검정 배경에 아주 큰 굵은 산세리프 "Design less. Ship Better." 두 번째 줄은 회색으로 한 단계 물러나 있다. 아래에 검색창, 그리고 실제 대시보드 화면이 코드 파일 이름표(`dashboard-shell.tsx`)를 단 창으로 떠 있다.

## 왜 좋은가
- **제목 두 줄의 명도 차이.** 첫 줄은 흰색, 둘째 줄은 회색. 같은 크기인데 밝기만으로 주와 부를 나눈다. 글자에 그라데이션도 입혀져 있다(글자색 투명 + 배경 클립)
- **컴포넌트를 실제 제품 화면 안에서 보여준다.** 버튼 하나를 따로 보여주는 대신, 대시보드 전체 안에 넣어서 "이걸 쓰면 이런 제품이 나온다"를 보여준다
- **파일 이름표가 달린 창.** 미리보기 창 위에 `analytics-dashboard.tsx` 같은 파일명을 붙여 개발자에게 바로 복사해 쓸 수 있다는 신호를 준다
- **숫자가 돌아가는 카운터.** 대시보드 지표가 자릿수마다 0~9가 굴러가며 맞춰지는 오도미터 방식

## 레이아웃
- 위: 왼쪽 로고, 오른쪽 검색, 후원, 템플릿, 테마 전환, 메뉴
- 히어로: 왼쪽 정렬 거대한 제목 2줄, 설명, 아바타 묶음 + 환영 문구, 기술 태그(React, TypeScript, Tailwind), 버튼, 검색창
- 이후: 대표 컴포넌트 미리보기 창들, 후원사, 푸터

## 타이포

- 본문: Geist, 12~16px
- 큰 제목과 작은 본문의 대비가 크다

## 색
- 배경: 순수 검정
- 글자: 흰색 → 회색 위계
- 버튼: 흰 알약(주 행동), 어두운 회색(보조)
- 강조: 노란 아이콘 정도. 거의 무채색

## 질감
- 얇은 회색 테두리 카드, 둥근 모서리
- 미리보기 창에 파일 이름표

## 모션
- 숫자 오도미터 카운터
- 컴포넌트 미리보기 안 애니메이션 (로딩 점, 탭 전환)
- Motion(옛 Framer Motion) 기반

## 레시피 후보
컴포넌트 목록에서 확인한 것. MIT라 원리를 참고해 다시 구현해도 된다. 그래도 코드를 그대로 복사하기보다 레시피 형식으로 새로 쓴다.
- **Flip Text** (글자 애니메이션): 글자가 뒤집히며 바뀌는 효과 → kinetic-type 레시피 후보
- **Text reel** (글자 애니메이션): 단어가 릴처럼 돌아가며 바뀜 → 히어로 문구 교체
- **Draggable Marquee** (스크롤 애니메이션): 끌어서 움직일 수 있는 무한 흐름 띠
- **Hover Image** (미디어): 링크 위에 올리면 이미지가 따라 뜨는 효과
- **Art Gallery**, **Split Showcase**: 작품 갤러리, 좌우 분할 쇼케이스
- **숫자 오도미터**: 지표가 자릿수별로 굴러 맞춰짐
- **Discover Button**, **Status Bars**, **Active Sessions**: 마이크로 인터랙션, 대시보드 부품

## 가져올 수 있는 것
- 제목 두 줄을 밝기 차이로 주와 부로 나누기
- 컴포넌트나 기능을 실제 제품 화면 안에 넣어 보여주기
- 개발자 대상이면 미리보기 창에 파일 이름표
- 지표 숫자에 오도미터 카운터

## 주의할 것
- React + Tailwind + Motion 전제다. 순수 HTML 결과물에 넣으려면 원리만 가져와 다시 짠다
- 검정 바탕 + 회색 글자는 대비가 쉽게 떨어진다. 회색 둘째 줄도 큰 글자 기준 3:1 이상인지 확인
