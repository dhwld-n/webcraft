## 첫인상
흰 화면 가운데에 좁은 카드 한 장. 세리프로 "Designer. Director."라고 쓰여 있고, 아래에 작업 슬라이드와 번호 매긴 프로젝트 목록. 웹사이트라기보다 휴대폰 앱 한 화면을 데스크톱에 띄운 느낌.

## 왜 좋은가
- **포트폴리오를 한 화면 안에 압축했다.** 페이지 높이가 화면 1.5배 정도. 소개, 대표 작업, 추천사, 프로젝트 목록이 좁은 카드 하나에 다 들어간다. 바쁜 채용 담당자가 10초 안에 판단할 수 있다
- **추천사가 작업 슬라이드와 함께 바뀐다.** 작업 이미지 아래에 그 작업 관련 추천사가 붙어 있어, 결과물과 평판을 같이 보여준다
- **번호 붙인 접이식 목록.** "01 Cash App Homepage +"처럼 프로젝트를 목록으로 보여주고 눌러서 펼친다. 정보량이 많아도 깔끔하다
- **하단에 떠 있는 질문 입력창.** "클라이언트 받고 있어요?" 같은 문구가 바뀌며 표시되는 채팅형 입력창으로 방문자가 바로 질문하게 한다
- 상단 오른쪽에 "통화 예약", "이메일 보내기" 버튼 두 개만. 목표 행동이 분명하다

## 레이아웃
- 화면 가운데 좁은 열(약 600px)의 연회색 카드, 바깥은 흰 여백
- 카드 안: 세리프 제목 → 한 줄 소개 → 작업 슬라이드(점 표시) → 추천사 → 번호 목록 → 작은 대문자 모노스페이스 문구
- 고정 요소: 위쪽 작은 아바타와 버튼 두 개, 아래쪽 질문 입력창

## 타이포
- 제목: Instrument Serif, 42px, 자간 좁게(-1.26px)
- 본문: 작은 산세리프, 보조 정보는 작은 대문자 모노스페이스
- 세리프 제목 하나가 전체 분위기를 결정한다

## 색
- 바탕: 흰색, 카드: 아주 연한 회색
- 글자: 진한 회색 `rgb(35,35,35)`
- 버튼: 검정 알약 (주 행동), 흰 알약 (보조)
- 색은 작업 이미지가 담당

## 질감
- 둥근 카드, 둥근 알약 버튼
- 그림자 거의 없음, 테두리 없음

## 모션
- 작업 슬라이드 자동 넘김, 추천사가 같이 바뀜
- 하단 입력창의 질문 문구가 바뀌며 표시됨
- 접이식 목록 펼침

## 가져올 수 있는 것
- 개인 포트폴리오를 좁은 한 장짜리 카드로 압축하는 구성
- 작업물과 추천사를 짝지어 슬라이드
- 프로젝트를 번호 매긴 접이식 목록으로
- 하단 고정 질문 입력창 (실제 AI 응답 대신 문의 폼으로 연결해도 된다)

## 주의할 것
- 작업물이 적거나 약하면 이 압축 구성이 더 휑해 보인다
- 데스크톱에서 좁은 열은 여백이 너무 많아 보일 수 있다. 바깥 여백에 은은한 배경이 필요할 수 있다
