# daisyUI

- url: https://daisyui.com
- styles: bento-grid, minimalism, cyberpunk, retro, pop-art
- industry: UI 컴포넌트 라이브러리 (Tailwind 플러그인, MIT)
- mood: 깔끔함, 친근함, 체계적, 테마 놀이
- analyzed_at: 2026-11-06
- 비고: 사이트보다 **테마 토큰**이 쓸모 있다. 35개 테마의 색, 둥글기, 테두리, 깊이, 노이즈 값을 아래 "테마 토큰"에 옮겼다 (MIT, 값은 패키지 `daisyui@5.0.0/themes.css`에서 읽음)

## 첫인상
흰 바탕 왼쪽에 굵은 제목 한 줄 + 가는 제목 한 줄, 오른쪽에 기울어진 컴포넌트 판들이 겹쳐 떠 있다. 라이브러리 소개답게 "이걸로 이런 화면을 만든다"를 첫 화면에서 바로 보여 준다.

## 왜 좋은가
- **굵기 대비로 만든 제목.** 같은 Outfit 글꼴을 첫 줄은 굵게, 둘째 줄은 굵기 100으로 써서 한 문장에 강약이 생긴다. 서체를 바꾸지 않고도 위계가 선다
- **기울어진 3D 판.** 컴포넌트 묶음을 원근으로 기울여 겹쳐 둔다. 평면 스크린샷보다 공간감이 있고, 내용이 작아도 화려해 보인다
- **테마를 바꾸면 사이트 전체가 바뀐다.** 색, 둥글기, 테두리 두께, 깊이(그림자), 노이즈를 토큰 몇 개로 묶었다. 스타일을 "색 + 모양 + 질감"의 작은 묶음으로 정의하는 좋은 예다
- **섹션 바탕색으로 테마를 보여 준다.** 아래로 내리면 흰 바탕 사이에 보라 `#422ad5`, 분홍 `#f861b4`, 남색 `#0c1425` 섹션이 끼어 테마 예시가 된다

## 레이아웃
- 첫 화면: 왼쪽 48% 폭에 제목·설명·버튼 두 개, 오른쪽에 기울어진 판 묶음이 화면 밖으로 넘친다
- 버튼 두 개는 같은 크기, 하나는 흰 테두리, 하나는 검정 면(높이 약 48px, 알약)
- 아래쪽은 기능 카드 그리드(2열, 3열 혼합, 간격 8px), 테마 미리보기, 후기 순
- 페이지가 아주 길다 (29화면). 컴포넌트 미리보기가 많다

## 타이포
- 제목 Outfit 50~72px, 굵기 100과 굵은 굵기를 한 문장에 섞는다
- 본문은 시스템 산세리프, 코드와 라벨은 ui-monospace 12px
- 제목과 본문 크기 비 4.2배

## 색
- 기본 테마: 배경 `#ffffff`, 글자 `#18181b`, 면 `#f8f8f8`, 강조는 섹션마다 다른 테마 색
- 의미 색 여섯 가지(primary, secondary, accent, info, success, warning)를 같은 채도로 맞춘다

## 질감
- 둥글기: 필드 4~8px, 박스 16px, 버튼 알약
- 그림자가 아주 많다 (185개). 대부분 옅은 넓은 그림자로 판을 띄운다
- 테두리 1~2px

## 모션
- 가장 인상적인 것: 호버 때 1000ms 동안 `cubic-bezier(1, 0, 0, 1)`로 바뀐다. 처음엔 가만히 있다가 끝에서 확 바뀌는 느린 곡선
- 일반 호버는 150~500ms, `cubic-bezier(0.4, 0, 0.2, 1)`
- 커서 효과 없음

## 가져올 수 있는 것
- 한 글꼴에서 굵기 대비(굵게 + 굵기 100)로 제목 두 줄 만들기
- 제품 화면을 원근으로 기울여 겹친 판으로 보여 주기
- 스타일을 토큰 묶음(색 5개 + 둥글기 2개 + 테두리 + 깊이 + 노이즈)으로 정의하기. 아래 테마 표를 스타일 카드의 출발점으로 쓴다
- 느린 호버 곡선 `cubic-bezier(1, 0, 0, 1)` 1000ms (기다렸다가 확 바뀜)

## 주의할 것
- daisyUI 기본 모양 그대로 쓰면 "Tailwind 템플릿" 티가 난다. 토큰 값만 참고하고 레이아웃은 새로 만든다
- 의미 색 여섯 가지를 한 화면에 다 쓰면 산만하다
