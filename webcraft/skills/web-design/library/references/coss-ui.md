- url: https://coss.com/ui
- styles: dark-tech, swiss
- industry: UI 컴포넌트 라이브러리 (Base UI 기반, 개발자와 AI용)
- mood: 담백함, 정돈, 실용, 중립
- analyzed_at: 2026-11-01
- 라이선스: 오픈소스 ("open source, open heart, open mind" 푸터 문구, GitHub 별 1만 8백 개). 단, GitHub `cosscom/coss` 저장소 전체는 **AGPL-3.0**(일부 SDK는 MIT)이고, coss ui 컴포넌트가 어느 라이선스인지는 확인하지 못함. 코드를 쓰기 전에 반드시 확인한다
- 비고: 약 800px 너비 화면에서 확인함. 첫 화면과 일부 카드만 선명하게 보였고 아래쪽은 그려지다 말았다

## 첫인상
짙은 회색 화면에 굵은 제목 "A new, modern UI component library built on top of Base UI." 아래로 아코디언, 알림, 아바타, 배지, 버튼 같은 기본 부품이 2열 카드로 끝없이 이어진다. 화려함 없이 기본기를 파는 사이트.

## 왜 좋은가
- **미리보기를 와이어프레임으로 추상화했다.** 카드 안에 실제 컴포넌트 대신 회색 막대와 점으로 그린 축소 그림을 넣었다. 수십 개가 나란히 있어도 시끄럽지 않고 모양만으로 구분된다
- **카드 하나의 틀이 단단하다.** 이름(굵게) → 한 줄 설명(회색) → 아래쪽 미리보기 칸. 이 틀을 50개 넘게 반복해도 지루하지 않다
- **"Built for developers and AI."** 사람뿐 아니라 AI 코딩 도구가 쓰기 좋은 라이브러리라는 점을 앞에 내세운다
- 버튼 두 개 (시작하기, 529개 부품 보기)로 행동이 분명하다

## 레이아웃
- 위: 왼쪽 메뉴와 로고 "coss.com ui", 오른쪽 GitHub 별 수와 테마 전환
- 히어로: 왼쪽 정렬 굵은 제목 2줄, 짧은 부제, 흰 버튼 + 어두운 버튼
- 본문: 2열 카드 격자 (데스크톱에선 더 많은 열일 수 있음), 컴포넌트 이름 알파벳 순

## 타이포
- 자체 산세리프, 제목 36px 굵기 700
- 본문 16px 회색

## 색
- 배경: 거의 검정에 가까운 짙은 회색
- 카드: 한 단계 밝은 회색, 미리보기 칸은 더 어두운 회색
- 글자: 흰색, 보조 회색
- 강조색 거의 없음

## 질감
- 둥근 카드 (12px 내외), 얇은 테두리
- 와이어프레임 미리보기 (회색 막대, 원, 점)

## 모션
- 거의 없다. 스크롤 목록

## 레시피 후보
- 모션 레시피보다는 **컴포넌트 목록 페이지의 레이아웃 패턴**이 쓸모 있다
- **와이어프레임 썸네일**: 기능, 요금제, 템플릿 목록을 회색 막대 축소 그림으로 보여주는 카드 (SVG나 CSS 막대로 쉽게 만들 수 있다)

## 가져올 수 있는 것
- 많은 항목을 보여줄 때 실제 화면 대신 추상 와이어프레임 썸네일
- 이름 + 한 줄 설명 + 미리보기 칸의 단단한 카드 틀
- 개발자 대상 페이지에 GitHub 별 수를 신뢰 지표로

## 주의할 것
- 이 사이트 자체는 디자인 쇼케이스가 아니라 기본 부품 목록이다. 분위기 레퍼런스로는 약하고, 목록 레이아웃 참고용
- 회색 위 회색이라 대비가 낮다. 보조 글자가 4.5:1 이상인지 확인
