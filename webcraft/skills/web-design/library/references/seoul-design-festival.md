# 서울디자인페스티벌

- styles: swiss, maximalism
- industry: 전시, 행사, 문화
- mood: 대담함, 그래픽, 정돈된 혼돈, 축제, 한국적 모던
- analyzed_at: 2026-10-31
- 출처: GDWEB 선정작

## 첫인상
왼쪽에 하늘색 세로 띠, 오른쪽에 쨍한 줄무늬 패턴이 큰 곡선 액자 안에 들어 있다. 정돈된 스위스식 격자 위에서 그래픽이 마음껏 터진다.

## 왜 좋은가
- **고정된 왼쪽 띠가 길잡이이자 브랜드다.** 로고, 메뉴, 언어 전환이 모두 왼쪽 단색 띠에 붙어 있고, 스크롤하면 띠 색이 하늘색 → 형광 초록으로 바뀐다. 메뉴가 곧 그래픽 요소다
- **엄격한 격자 + 과감한 그래픽.** 콘텐츠는 1px 검은 선으로 나뉜 칸에 정확히 들어가고, 그 안의 이미지와 패턴은 원색으로 시끄럽다. 질서와 혼돈의 대비가 디자인 행사다움을 만든다
- **한글과 영문을 한 제목에 나란히.** "디자인 브랜드 참가 신청 / Brand registration"처럼 위아래로 쌓아 국제 행사 느낌과 정보 전달을 동시에
- **큰 곡선으로 깎은 이미지 액자.** 직선 격자 사이에 한쪽만 크게 둥근 모양이 들어가 단조로움을 깬다
- 칸 전체가 링크이고, 오른쪽 아래 `>` 화살표 하나로 클릭할 수 있다는 걸 알려준다

## 레이아웃
- 왼쪽 고정 띠 (화면 폭 약 18%): 위에 로고, 가운데 메뉴, 아래 언어 전환
- 오른쪽: 큰 히어로 슬라이더 (한쪽 모서리를 크게 둥글린 액자), 아래 행사 정보 박스
- 이후 2열 칸 그리드: 칸마다 위에 작은 영문 라벨, 아래 큰 한글 제목과 화살표
- 푸터: 뉴스레터 입력, 주소, 링크 목록, 외부 로고

## 타이포
- Neue Haas Grotesk Display (영문) + Pretendard (한글), 굵기 700
- 제목 44px, 칸 제목 28px. 모두 굵고 단단하다
- 작은 영문 라벨은 가볍게 위에 올린다

## 색
- 바탕: 흰색, 선: 검정 1px
- 왼쪽 띠: 하늘색 → 스크롤 후 형광 초록 (섹션마다 바뀜)
- 이미지와 패턴: 빨강, 파랑, 초록, 노랑, 분홍 원색 줄무늬
- 글자: 검정

## 질감
- 1px 검은 격자선, 그림자 없음
- 각진 칸 + 일부만 크게 둥근 액자
- 기하학적 줄무늬 패턴 (지그재그, 계단)

## 모션
- 히어로 슬라이더 (좌우 화살표)
- 왼쪽 띠 색이 스크롤 위치에 따라 바뀜
- 영상 몇 개, 나머지는 정적. 그래픽 자체가 시끄러워 모션은 절제

## 가져올 수 있는 것
- 메뉴를 담은 단색 고정 사이드 띠를 브랜드 요소로 쓰고, 섹션마다 색 바꾸기
- 1px 검은 격자로 칸을 나누고 칸 전체를 링크로
- 한글 제목 + 영문 보조 제목 쌓기 (한국어 국제 행사, 문화 기관에 좋다)
- 직선 격자 사이에 큰 곡선 하나로 리듬 만들기
- 한글은 Pretendard, 영문은 그로테스크 계열로 짝 맞추기

## 주의할 것
- 줄무늬 그래픽은 행사 고유 아이덴티티다. 패턴은 새로 만든다
- 원색 패턴이 많으면 글자 대비가 무너지기 쉽다. 글자는 항상 흰 칸 위에
- 왼쪽 고정 띠는 모바일에서 상단 바로 바꿔야 한다
