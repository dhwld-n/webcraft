## 첫인상
보랏빛 밤하늘에 별이 뜬 히어로, 그 위에 따뜻한 세리프 제목 "The Agentic Marketing OS for the AI era". 아래로 내려가면 분홍 구름과 소나무 산이 그려진 그림책 같은 풍경 위에 제품 화면이 얹혀 있다. AI SaaS인데 차갑지 않다.

## 왜 좋은가
- **AI 제품을 손으로 그린 풍경으로 감쌌다.** 보통 AI SaaS는 어두운 그라데이션과 빛 번짐인데, 여기는 회화풍 산과 구름. "사람의 목소리"를 강조하는 메시지와 맞는다
- **세리프 제목이 신뢰를 준다.** New Kansas 같은 둥근 세리프가 기술 문구를 부드럽게 만든다
- **추천사를 스크롤로 읽게 한다.** 큰 인용문의 단어들이 회색에서 검정으로 차례로 진해지며, 읽는 속도에 맞춰 문장이 완성된다
- **제품 데모를 실제 대화처럼.** "새 제품을 출시해요"라고 입력된 프롬프트 칸 아래 캠페인 카드, 숫자, 크리에이터 목록이 이어진다. 기능 설명 대신 사용 장면을 보여준다
- 고객사 로고 줄, 지원 플랫폼 로고 줄을 단색으로 정리해 신뢰를 조용히 쌓는다

## 레이아웃
- 위: 둥근 알약 모양의 떠 있는 헤더 (왼쪽 로고, 오른쪽 가입 버튼 + 메뉴)
- 히어로: 밤하늘 배경, 가운데 정렬 세리프 제목 2줄, 설명, 흰 알약 버튼 + 어두운 반투명 "트레일러 보기" 버튼
- 로고 줄 → 큰 인용문 (스크롤 단어 강조)
- 기능 섹션: 둥근 큰 카드 안에 회화풍 풍경 배경 + 세리프 제목 + 그 위에 흰 제품 UI 카드
- 결제 섹션: 크리에이터 목록, 합계, 검정 결제 버튼 (실제 UI처럼)

## 가져올 수 있는 것

- 추천사를 스크롤 연동 단어 강조로 (scroll-reveal 레시피를 단어 단위로 응용)

- 색을 oklch로 관리하면 밝기 단계를 맞추기 쉽다

## 주의할 것
- 회화풍 풍경은 직접 그리거나 생성해야 한다. 이 사이트의 그림을 가져오지 않는다
- 풍경 위 흰 글자는 하늘 밝은 부분에서 대비가 약해진다
